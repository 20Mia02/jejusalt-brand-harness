## 🚀 빠른 시작 (5분 안에 시작하기)

### 1단계: 프로그램 설치 및 실행

#### Windows/Mac에서:

```bash
# 1. 프로젝트 폴더 열기
cd jejusalt-brand-harness

# 2. 필요한 라이브러리 설치 (처음 1회만)
npm install

# 3. 프로그램 시작
npm start
# 또는 개발자 모드
npm run dev
```

**완료!** 웹 브라우저가 자동으로 열립니다:
```
http://localhost:5000
```

- ✅ 페이지가 정상 로드되었는지 확인

- ✅ "AI 분석" 버튼이 보이는지 확인

준비 완료! 👍

## 📋 단계별 사용 가이드

### 🎯 목표: 제주소금 마케팅 영상 1개 완성하기 (총 5~10분)

#### **Step 1️⃣: 웹사이트 접속**

```
주소: http://localhost:5000
```

화면을 보면:
- 상단: "제주소금 AI 마케팅 플랫폼" 제목
- 왼쪽: 입력 폼 (제주소금 정보 입력)
- 오른쪽: 자료 목록 및 필터

---

#### **Step 2️⃣: 제주소금 정보 입력**

아래 정보를 입력 폼에 작성하세요:

```
📝 제품명: 제주소금
📝 설명: 제주 청정 해역에서 채취한 천연 소금, 건강식 영양소 풍부
📝 키워드: 웰빙, 프리미엄, 건강, 자연
📝 타겟 나이: 30대~50대
```

**또는** 미리 입력된 샘플 데이터 사용:
- "건강한 식생활"
- "프리미엄 웰빙"
- "천연 소금"

---

#### **Step 3️⃣: AI 자동 분석 시작**

"🚀 **AI 분석 시작**" 버튼을 클릭하세요.

**화면에 나타나는 것:**
```
✅ 상품 분석 완료
✅ 타겟 고객층 분석 완료
✅ 마케팅 포인트 추출 완료
```

**분석 결과 (자동으로 표시):**
- 📊 카테고리: 식품 > 건강식품
- 👥 추천 타겟: 20대~40대, 건강 관심층
- 🎯 마케팅 포인트: 자연성, 프리미엄감, 웰빙

---

#### **Step 4️⃣: 캐릭터 선택**

AI가 **3명의 캐릭터**를 추천합니다:

```
1️⃣ "헬씨엘리트" (30대 직장 여성, 건강식 전문가)
   → 전문성 있는 톤, 신뢰도 높음

2️⃣ "웰빙매니아" (40대 주부, 가족 건강 중심)
   → 따뜻하고 공감 가능한 톤

3️⃣ "영양슈퍼맨" (20대 피트니스 전문가, 활기찬 남성)
   → 에너지 넘치고 젊은 톤
```

**당신의 목표에 맞는 캐릭터 1개를 선택하세요:**

예: 중년 여성 타겟 → "웰빙매니아" 선택

---

#### **Step 5️⃣: 콘텐츠 생성 시작**

"🎬 **AI 콘텐츠 생성**" 버튼을 클릭하세요.

**자동으로 진행되는 단계 (Step 4~9):**

```
Step 4: 캐릭터 상세 분석 중... ⏳
   → 선택한 캐릭터의 성격, 음성톤, 표현 방식 분석

Step 5: 120초 시나리오 작성 중... ⏳
   → "제주소금의 효능을 가족 밥상에 담다" 같은 스토리 생성

Step 6: 영상 제목 생성 중... ⏳
   → "웰빙의 맛, 제주소금"

Step 7: 마케팅 카피 작성 중... ⏳
   → 각 SNS (인스타그램, 유튜브 등)용 문구 생성

Step 8: 컴플라이언스 검증 중... ⏳
   → 법적으로 안전한지 확인 (의약품 표시금지 등)

Step 9: Higgsfield AI 영상 생성 중... 📹
   → 최종 영상 완성 (가장 오래 걸림)
```

---

#### **Step 6️⃣: 진행도 확인 (기다리기)**

화면에 **진행률 바**와 **현재 단계**가 표시됩니다:

```
███████░░░░░░░░░░  65%
현재: Step 8 컴플라이언스 검증 중...

이 과정은 2~5분 정도 소요됩니다...
```

**이 시간에 할 수 있는 것:**
- 커피 마시기 ☕
- 다른 자료 입력해보기
- 페이지를 벗어나도 됨 (자동 저장됨)

---

#### **Step 7️⃣: 완성된 영상 재생**

```
✅ 완료! 영상이 생성되었습니다!
```

화면에 나타나는 것:
- 📹 **영상 플레이어**: 생성된 120초 영상 재생
- 📊 **검증 결과**: "APPROVED" (컴플라이언스 통과)
- 📋 **생성된 카피**: 시나리오 전문, SNS용 텍스트 등
- 📥 **다운로드 링크**: 영상 URL 복사 가능

**영상 다운로드:**
```
1. "📋 복사" 버튼으로 링크 복사
2. 파일 저장하거나
3. SNS에 직접 공유
```

## ❓ 자주 묻는 질문 (FAQ)

### Q1: 영상은 누가 만드나요?
**A:** Higgsfield AI라는 전문 영상 생성 AI가 자동으로 만듭니다.
- 사람이 직접 촬영하지 않음
- AI가 캐릭터 목소리, 제스처, 배경 모두 생성
- 약 2~5분 내에 완성

### Q2: 영상 생성은 정말 자동인가요?
**A:** 네, 100% 자동입니다!
```
입력 → AI 분석 → 시나리오 작성 → 영상 생성 → 완료
(사람 개입 없음)
```

### Q3: 생성된 영상의 품질은 어떤가요?
**A:** 전문가 수준의 마케팅 영상입니다.
- 해상도: 720p (유튜브/인스타그램 표준)
- 길이: 120초 (짧은 영상 최적화)
- 품질: 상업용 광고 수준

### Q4: 영상 생성이 실패하면 어떻게 하나요?
**A:** 자동으로 재시도합니다.
```
1차 실패 → 2초 대기 후 자동 재시도
2차 실패 → 4초 대기 후 자동 재시도
3차 실패 → 오류 메시지 표시
```

### Q5: 캐릭터를 커스터마이징할 수 있나요?
**A:** 네! 관리자 모드에서 가능합니다.
```
기존 캐릭터 수정:
  → 성격, 목소리톤, 표현방식 등 변경

새 캐릭터 추가:
  → 완전히 새로운 캐릭터 생성
  → TimelyAI가 자동으로 분석
```

### Q6: 생성 비용은 얼마나 드나요?
**A:** 플랫폼 자체는 무료입니다.
```
비용 발생처:
  • Higgsfield AI 영상 생성 = 크레딧 소비
  • TimelyAI API = 월별 구독료
  (프로젝트 관리자가 결제)
```

### Q7: 얼마나 많은 영상을 만들 수 있나요?
**A:** 크레딧 남은 한도까지 무제한입니다.
```
예: 현재 크레딧 1,210개 보유
  120초 영상 1개 = ~5 크레딧 소비
  약 200개 영상 생성 가능
```

### Q8: 생성된 영상은 누가 소유하나요?
**A:** 제주소금(고객)이 소유합니다.
```
✅ 상업용 사용 가능
✅ SNS 업로드 가능
✅ 광고에 사용 가능
```

### Q9: 영상에 자막을 넣을 수 있나요?
**A:** 현재는 자동 생성되지 않습니다.
```
방법 1: 생성 후 별도 편집 도구로 추가
방법 2: 관리자에게 요청 (커스텀 수정)
```

### Q10: 모바일에서도 사용 가능한가요?
**A:** 네, 모든 기기에서 사용 가능합니다.
```
✅ 데스크톱 (최적화)
✅ 태블릿
✅ 스마트폰
```

## 🔧 트러블슈팅 (문제 해결)

### 문제 1️⃣: "서버에 연결할 수 없습니다" 오류

**원인:**
- 서버가 시작되지 않았음
- 포트 5000이 이미 사용 중

**해결 방법:**
```bash
# 1. 기존 서버 종료 (Ctrl+C)

# 2. 포트 확인 및 종료
# Windows:
netstat -ano | findstr :5000

# Mac/Linux:
lsof -i :5000

# 3. 서버 다시 시작
npm start
```

---

### 문제 2️⃣: "영상 생성 실패" 메시지

**원인:**
- Higgsfield API 임시 오류
- 인터넷 연결 불안정
- 특수문자 입력으로 인한 인코딩 에러

**해결 방법:**
```
1. "🔄 다시 생성" 버튼 클릭
2. 3초 기다렸다 다시 시도
3. 제품명에서 특수문자 제거 후 재시도
```

---

### 문제 3️⃣: AI 분석 결과가 이상함

**원인:**
- 제품 정보가 너무 짧음
- 키워드 입력 부족

**해결 방법:**
```
✏️ 제품 설명을 더 자세히 입력:
   × "소금"
   ✓ "제주 청정 해역에서 채취한 천연 소금, 
      미네랄 풍부, 건강한 식생활을 위한 프리미엄 제품"
```

## 🏗️ 기술 정보 (쉬운 설명)

### "내부적으로 어떻게 작동하나요?"

```
당신의 입력 (텍스트)
     ↓
┌─────────────────────────────────────┐
│         AI 분석 엔진                 │
│  (TimelyAI - 똑똑한 AI 어시스턴트)    │
│                                     │
│  역할: 텍스트를 분석하고              │
│        최적의 캐릭터/스토리 추천      │
└─────────────────────────────────────┘
     ↓
시나리오 & 카피 (텍스트)
     ↓
┌─────────────────────────────────────┐
│       영상 생성 엔진                 │
│  (Higgsfield AI - 영상 전문가)       │
│                                     │
│  역할: 시나리오를 영상으로 변환       │
│        (음성, 배경, 제스처 포함)      │
└─────────────────────────────────────┘
     ↓
완성된 영상 (MP4 파일)
```

### 🧠 각 단계에서 하는 일

| 단계 | 담당자 | 역할 |
|------|--------|------|
| 입력 | **당신** | 제주소금 정보 입력 |
| 분석 | **TimelyAI** | 시장 분석 & 타겟 파악 |
| 설계 | **TimelyAI** | 캐릭터 & 스토리 제안 |
| 작성 | **TimelyAI** | 시나리오 & 카피 작성 |
| 검증 | **TimelyAI** | 법적/윤리적 검증 |
| 제작 | **Higgsfield AI** | 영상 완성 |
