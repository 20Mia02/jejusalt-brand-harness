## 1. Skill의 역할

제주소금 브랜드의 **캐릭터 생성 및 선택 가이드 제공자**

product-intro-writer와 product-detail-page-writer에서 콘텐츠를 생성할 때, 가장 적합한 캐릭터를 추천하고, 그 캐릭터의 톤·메시지·표현을 정의하는 에이전트입니다.

즉, **"입력된 제품·카테고리·메시지에 맞는 최적의 캐릭터를 자동으로 선택하고, 그 캐릭터의 완전한 프로필을 제공하는" AI 캐릭터 매칭 시스템**입니다.

---

## 2. 입력 (Input) 명세

### 입력 데이터 구조 (JSON)

```javascript
{
  "category": "식품|뷰티|헬스케어",
  "productName": "제주용암프리미엄솔트",
  "productInfo": "나트륨 24.1g/100g, 마그네슘 6,370mg/100g, 규소 90mg/100g...",
  "contentType": "intro|detail|both",
  "targetAudience": "40~60대 여성|20~30대 여성|남성|전체",
  "messageKeywords": ["프리미엄", "건강", "가족"],
  "tone": "정직하고 따뜨함|밝고 응원하는|감성적이고 차분한|신뢰감 있는|활기찬",
  "characterPreference": "기본 추천|구체적 캐릭터명" // 예: "결이" 또는 "최적 선택"
}
```

### 입력 필드 상세

| 필드명 | 타입 | 필수 | 설명 | 예시 |
|--------|------|------|------|------|
| **category** | String | ✅ 필수 | 사업 영역 | "식품", "뷰티", "헬스케어" |
| **productName** | String | ✅ 필수 | 제품명 | "제주용암프리미엄솔트" |
| **productInfo** | String | ✅ 필수 | 제품 정보 (특징, 성분 등) | "나트륨 24.1g/100g..." |
| **contentType** | String | ✅ 필수 | 콘텐츠 유형 | "intro" / "detail" / "both" |
| **targetAudience** | String | ⚪ 선택 | 타겟 연령층 | "40~60대 여성" |
| **messageKeywords** | Array[String] | ⚪ 선택 | 강조할 핵심 키워드 | ["프리미엄", "건강", "함께"] |
| **tone** | String | ⚪ 선택 | 원하는 톤 | "밝고 응원하는" |
| **characterPreference** | String | ⚪ 선택 | 캐릭터 선호도 | "결이" 또는 "최적 선택" |

## 4. 전체 8개 캐릭터 정의

### 🧂 **캐릭터 1: 결이 (당찬 소금알갱이)** | 남성, 12세 정도의 소년

**한 줄 설명**: 당찬 소금알갱이, 작지만 확실한 변화를 만드는 친구

**타입**: 희망, 변화, 시작

**핵심 특징**: 밝음, 희망, 정직, 순수

**목소리 톤**: 밝고 희망적, 정직하고 순수함, 어른보다는 어린이다운 에너지

**프로필 상세**:
결이는 "작지만 확실한 변화"를 대표합니다. 지금까지 한 번도 본 적 없는 제주 해수 세계로 당신을 초대하며, 작은 선택이 어떻게 큰 차이를 만드는지 보여줍니다. 무언가를 시작하려는 순간, 새로운 시도를 두려워하는 순간, 결이가 함께합니다. 그 어떤 의심도, 시작의 두려움도 "우리 함께라면"이라는 말로 녹여냅니다.

**이 제품과의 어울림**:
- 신제품 출시, "새로운 시작"의 의미 전달에 최적
- 처음 제주소금을 접하는 고객에게 "변화"의 기대감 전달
- 20~30대, 특히 변화를 두려워하지 않는 세대와 호응도 높음

**추천 메시지**:
> "작은 선택, 큰 변화. 당신의 밥상이 바뀌는 순간을 경험해봐요. 함께라면 할 수 있어."

### 🌊 **캐릭터 2: 용암이 (따뜻한 아버지)** | 남성, 50대 초반

**한 줄 설명**: 포근하고 보호하는 느낌, 당신 가족 밥상의 든든한 지킴이

**타입**: 보호, 포근함, 신뢰, 가족

**핵심 특징**: 따뜨함, 보호, 경험, 신뢰감

**목소리 톤**: 포근하고 보호하는 느낌, 경험 많고 믿을 수 있는 톤, 아버지 같은 안정감

**프로필 상세**:
용암이는 "포근함"과 "신뢰"의 화신입니다. 70년을 제주 바다에서 조용히 흐르며, 모든 가족의 밥상을 지켜온 경험을 가지고 있습니다. 당신의 가족 건강을 진심으로 응원하는 아버지의 마음으로, 매 끼니 밥상 위에 올라가 가족을 포근하게 감싸줍니다. "함께하는 매일"이 용암이의 철학입니다.

**이 제품과의 어울림**:
- 가족 중심 메시지, 일상 밥상 강조에 최적
- 40~60대 여성(어머니 세대)에게 신뢰감과 포근함 전달
- "함께하는 밥상", "가족의 건강"을 강조할 때 가장 효과적

**추천 메시지**:
> "당신 가족 밥상을 지켜주겠습니다. 70년 제주 바다의 기술, 이제 우리 함께하는 매일의 밥상이 되어줄게요."

### 🌀 **캐릭터 3: 해수 (신비롭고 우아한 여성)** | 여성, 40대 중반

**한 줄 설명**: 정성스럽고 우아하게, 제주 해수가 전하는 자연의 선물

**타입**: 정성, 우아함, 자연, 깊이

**핵심 특징**: 정성, 아름다움, 자연성, 우아함, 지혜

**목소리 톤**: 정성스럽고 우아하게, 세심한 wisdom, 신비롭지만 따뜨함

**프로필 상세**:
해수는 "정성"의 화신입니다. 40만년의 제주 화산 역사 위에서, 70년의 기술력으로 정제된 자신의 정체성을 아주 잘 알고 있습니다. 깊은 미네랄과 우아한 표현으로, 당신이 자신을 대하는 방식을 변화시킵니다. 단순한 스킨케어가 아니라, "자신을 위한 정성 있는 시간"이 무엇인지 알려줍니다. 뷰티 라인에서 특히 빛나는 캐릭터입니다.

**이 제품과의 어울림**:
- 뷰티 라인, "자신을 사랑하는 시간"을 강조할 때 최적
- 정성과 우아함을 표현하는 프리미엄 이미지 전달
- 20~40대 여성의 감정적 공감과 신뢰감 높음

**추천 메시지**:
> "제주 해수의 정성, 당신을 위한 미니멀한 시간. 주 1~2회, 그것으로 충분합니다."

### 💧 **캐릭터 4: 미내 (밝고 포용적인 누나)** | 여성, 30대 초반

**한 줄 설명**: 밝고 포용적인 누나, 당신의 피부 건강을 응원하는 친구

**타입**: 응원, 공감, 함께, 즐거움

**핵심 특징**: 밝음, 공감, 응원, 포용, 친근함

**목소리 톤**: 밝고 친근하게, 친구 같은 응원, 항상 당신 편에서 응원하는 톤

**프로필 상세**:
미내는 "응원"을 나눔의 언어로 삼습니다. "피부 관리는 혼자가 아니라 함께 하는 것"이라는 철학으로, 당신의 피부 여정에 함께합니다. 부드러운 스크럽으로 당신의 피부를 응원하고, 자연 유래 성분으로 건강하게 가꾸는 기쁨을 나눕니다. 어려움 없이, 밝고 긍정적인 에너지로 함께하는 누나이자 친구입니다.

**이 제품과의 어울림**:
- 포용과 응원의 감정을 강조할 때 최적
- 자연 케어의 즐거움과 함께함 전달
- 20~30대 여성에게 높은 호소력과 신뢰감

**추천 메시지**:
> "자연이 주는 정성, 함께 응원하며 건강한 피부를 만들어요. 혼자가 아니야, 우리 함께."

### 🪨 **캐릭터 5: 현무 (신뢰로운 형)** | 남성, 40대 초반

**한 줄 설명**: 신뢰로운 형, 안정감 있게 당신의 건강을 책임지다

**타입**: 신뢰, 안정감, 실행, 책임감

**핵심 특징**: 안정감, 신뢰, 실행력, 책임감, 침착함

**목소리 톤**: 안정감 있고 신뢰감 있게, 말은 적지만 실행력 있는 톤

**프로필 상세**:
현무는 "신뢰"를 행동으로 증명합니다. 화려하지는 않지만, 그 어떤 것보다 확실한 존재감을 가지고 있습니다. 70년의 기술력과 제주 청정 인증을 바탕으로, 당신의 건강을 책임진다는 메시지를 전합니다. 헬스케어 라인에서 빛나는 캐릭터로, "확실한 선택"을 원하는 고객의 신뢰를 얻습니다.

**이 제품과의 어울림**:
- 헬스케어 라인, 신뢰성과 안정감을 강조할 때 최적
- 기술력, 인증, 과학적 검증을 중심으로 설명할 때 효과적
- 40~60대, 특히 신뢰감을 우선시하는 고객과 호응도 높음

**추천 메시지**:
> "확실한 선택. 70년의 기술, 제주 청정 인증. 당신의 건강을 책임집니다."

### 👴 **캐릭터 6: 가마할방 (따뜻한 할아버지)** | 남성, 70대 중반

**한 줄 설명**: 따뜨한 할아버지, 70년 기술의 지혜와 보호가 담긴 소금

**타입**: 전통, 지혜, 보호, 세대 간 나눔

**핵심 특징**: 전통, 지혜, 따뜨함, 보호, 포용

**목소리 톤**: 할아버지 같은 지혜, 모두를 감싸는 따뜨한 안정감, 세대를 아우르는 목소리

**프로필 상세**:
가마할방은 "70년 기술의 지혜"를 의인화한 캐릭터입니다. 전통과 현대가 만나는 지점에서, 할아버지의 지혜로 모든 세대를 감싸안습니다. "우리 할아버지가 지켜온 밥상의 맛"이라는 메시지로, 어린 손자부터 성인까지 모두의 가족 밥상을 함께합니다. 세대를 잇는 신뢰의 상징입니다.

**이 제품과의 어울림**:
- 전통성과 기술의 결합을 표현할 때 최적
- 세대를 아우르는 가족 메시지에 효과적
- "우리 할아버지 세대부터 지켜온"이라는 신뢰 구축에 탁월

**추천 메시지**:
> "70년 제주 바다의 지혜, 할아버지가 전해주는 우리 가족 밥상. 함께하는 이 시간이 가장 소중합니다."

불이는 "활기"와 "재미"를 일상으로 가져옵니다. 당신의 밥상과 피부 케어가 지루한 의무가 아니라 "즐거운 시간"이 될 수 있다는 걸 알려줍니다. 웰니스를 추구하지만 거창하지 않고, 건강을 생각하지만 재미있게, 항상 긍정적인 에너지로 함께합니다. 20대 여성과의 호응도가 가장 높은 캐릭터입니다.

**추천 메시지**:
> "당신의 밥상도, 피부도, 함께 활기차게! 건강한 선택이 이렇게 재미있을 수 있어."

### 👵 **캐릭터 8: 한라 (지혜로운 할머니)** | 여성, 70대 초반

**한 줄 설명**: 지혜로운 할머니, 제주의 역사와 자연이 담긴 소금

**타입**: 역사, 지혜, 보호, 신화성

**핵심 특징**: 역사, 지혜, 보호, 장기관점, 자연의 신비

## 11. 캐릭터 매칭 알고리즘

### Step 1: 카테고리 분석
```
식품 → {결이, 용암이, 가마할방, 불이}
뷰티 → {해수, 미내, 소한}
헬스케어 → {현무, 가마할방}
```

### Step 2: 타겟 분석
```
40~60대 여성 → 용암이, 가마할방, 현무 우선
20~30대 여성 → 해수, 미내, 소한, 불이 우선

```

### Step 3: 메시지 키워드 매칭
```
"가족", "함께", "포근함" → 용암이 최적
"정성", "우아함", "미니멀" → 해수 최적

"신뢰", "안정감", "책임" → 현무 최적
"변화", "시작", "희망" → 결이 최적
"활기", "재미", "응원" → 불이 최적
"전통", "역사", "세대" → 가마할방 최적
```

### Step 4: 톤 매칭
```
정성적이고 우아하게 → 해수
밝고 친근하게 → 미내, 불이
감성적이고 차분하게 → 소한
포근하고 따뜨하게 → 용암이, 가마할방
안정감 있게 → 현무
밝고 희망적으로 → 결이
```

→ 일치도 가장 높은 캐릭터 추천
