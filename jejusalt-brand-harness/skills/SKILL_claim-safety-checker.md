## 1. Skill의 역할

제주소금 제품 카피의 **의료 표현 & 과장 표현 검증자**

product-intro-writer와 product-detail-page-writer로 생성된 텍스트를 검증하여, brand-voice.md의 "정직하게, 과장 없이" 원칙이 지켜지고 있는지 자동으로 확인합니다.

즉, **"법적·윤리적으로 안전한 마케팅 카피인가?"를 판정하는 AI 검증 에이전트**입니다.

## 4. 핵심 검증 항목

### 1️⃣ 의료 표현 금지 (CRITICAL!)

이 항목은 **식품표시광고법** 위반 가능성이 있으므로 가장 엄격합니다.

#### ❌ **절대 금지 표현들**

```
"효과가 있다/있습니다"
"개선된다/됩니다"
"치유한다/합니다"
"완화한다/합니다"
"증상을 줄인다"
"질병을 예방한다"
"혈압을 낮춘다"
"혈액순환을 개선한다"
"염증을 없앤다"
"면역력을 높인다"
"에너지를 회복한다" (의료적 의미)
"피로를 풀어준다" (의료적 의미)
"건강을 회복한다"
"체질을 개선한다"
"독소를 제거한다"
"손상된 세포를 재생한다"
```

#### ⚠️ **주의할 표현들** (문맥에 따라 위험할 수 있음)

```
"[성분] 함유" (OK) vs "[성분]이 [의료 효능]한다" (X)
"[수치]mg/100g" (OK) vs "[수치]mg으로 효과를 본다" (X)
"건강" (문맥 주의) - "건강한 식습관을 돕습니다" (OK) vs "건강을 증진합니다" (X)
"케어", "관리" (OK) vs "치료", "치유" (X)
"좋다" (문맥 주의) - "밥상에 좋습니다" (OK) vs "건강에 좋습니다" (X - 의료 의미)
```

#### ✅ **OK 표현들**

```
"나트륨 24.1g/100g을 함유하고 있습니다"
"마그네슘 6,370mg/100g의 풍부한 미네랄"
"제주 청정 인증을 받았습니다"
"70년 전통 기술로 추출되었습니다"
"[성분]을 함유하고 있습니다" (기술적 설명)
"미네랄이 풍부한 소금"
"나트륨 함량이 낮습니다"
"건강한 식습관의 기초가 됩니다"
"밥상을 풍요롭게 해줍니다"
"가족을 함께할 때 선택하는 소금"
```

### 2️⃣ 과장 표현 금지 (CRITICAL!)

윤리적 문제와 소비자 기만 방지를 위한 항목입니다. 2개 이상 발견되면 FAILED입니다.

#### ❌ **절대 금지 표현들**

```
"최고의", "최고 품질의", "최상의"
"기적의", "기적 같은", "기적이다"
"유일무이한", "유일하게", "유일한"
"세상에 하나뿐인", "이것만이 가능한"
"모두가", "누구나", "확실히" (절대적 표현)
"완벽한", "100% 완벽", "100% 무결"
"대박", "신의 선택", "선택받은 제품"
"세계 최고", "국내 유일", "유일한 기술"
"혁명적인" (근거 없이)
"획기적인" (근거 없이)
"더할 나위 없이 좋다"
"금상첨화"
"최강"
"압도적"
"무패"
```

#### ⚠️ **주의할 표현들** (문맥에 따라 위험할 수 있음)

```
"가장" (비교급) - 근거 있어야 함
  OK: "일반 소금 대비 가장 낮은 나트륨"
  X: "가장 좋은 소금"
  
"유명하다" - 객관적 근거 필요
  OK: "많은 고객들이 선택해주고 있습니다"
  X: "세상에서 가장 유명한 소금"
  
"인기 있다" - 객관적 근거 필요
  OK: "월 판매량이 증가하고 있습니다"
  X: "가장 인기 많은 소금"
  
"특별하다", "특별함" - 구체적 근거 필요
  OK: "제주 해수에만 있는 특별한 미네랄"
  X: "특별함 그 자체"
```

#### ✅ **OK 표현들**

```
"일반 소금 대비 40% 감소"
"제주 해수에만 있는 자연 성분"
"70년 경험의 기술"
"고객들이 선택해주시는 제품"
"매달 새로운 고객들이 찾아주고 있습니다"
"제주만의 프리미엄 소금"
"전통과 기술이 만난 결과"
"우리가 자랑하는 제품"
"많은 분들의 사랑을 받아왔습니다"
```

### 4️⃣ brand-voice 3원칙 준수도

#### ✅ **원칙 1: 정직하게 (근거 있는 수치만)**

**검증 기준**:
- [ ] 모든 수치가 제품정보(입력의 productInfo)와 일치하는가?
- [ ] 근거 없는 주장은 없는가?
- [ ] 객관적 사실만 기재되어 있는가?
- [ ] "아마도", "가능할 것", "일 수도" 같은 추측 표현은 없는가?

**평가 방식**:
- ✅ PASSED: 제품 사양 기준 100% 일치, 추측 표현 0개
- ⚠️ WARNING: 90% 이상 일치, 추측 표현 1~2개
- ❌ FAILED: 90% 미만 일치, 추측 표현 3개 이상

---

#### ✅ **원칙 2: 제주와 기술의 만남**

**검증 기준**:
- [ ] "제주 해수" 또는 "제주 용암" 또는 "제주" 언급이 있는가?
- [ ] "기술", "전통", "과학", "70년", "R&D" 같은 단어가 있는가?
- [ ] 자연과 과학의 조화를 표현하는가?
- [ ] 단순히 "좋은 제품"이 아니라 "왜 제주인가?"를 설명하는가?

**평가 방식**:
- ✅ PASSED: 제주 언급 있음 + 기술 언급 있음 + 조화 표현 있음
- ⚠️ WARNING: 제주 또는 기술 중 하나만 언급
- ❌ FAILED: 제주, 기술 모두 미언급 또는 약함

---

#### ✅ **원칙 3: 일상 속 소소한 함께함**

**검증 기준**:
- [ ] "당신", "우리 가족", "함께", "매일" 같은 일상 표현이 있는가?
- [ ] 구체적인 시나리오(아침 밥, 저녁 반찬, 국, 나물무침 등)가 있는가?
- [ ] 따뜻하고 공감하는 톤인가?
- [ ] 거창하지 않고 일상적인가?

**평가 방식**:
- ✅ PASSED: 일상 표현 2개 이상 + 구체적 시나리오 있음 + 따뜻한 톤
- ⚠️ WARNING: 일상 표현 1개 또는 시나리오 1개만
- ❌ FAILED: 일상 표현 없음 또는 거창한 톤

## 7. 검증 로직 알고리즘

### Step 1: 의료 표현 스캔
```
1. generatedContent에서 금지 표현 300+ 개 자동 검색
2. 발견될 때마다 "❌ CRITICAL" 카운트
3. 1개 이상 발견 → 의료 표현 검사 = FAILED
```

### Step 2: 과장 표현 스캔
```
1. generatedContent에서 과장 표현 200+ 개 자동 검색
2. 발견될 때마다 "❌ CRITICAL" 카운트
3. 2개 이상 발견 → 과장 표현 검사 = FAILED
4. 1개 발견 → WARNING
```

### Step 3: 신조어 스캔
```
1. generatedContent에서 신조어 100+ 개 자동 검색
2. 발견될 때마다 "⚠️ WARNING" 카운트
3. 2개 이상 발견 → 신조어 검사 = WARNING
4. 1개 발견 → PASSED (하지만 감점)
```

### Step 4: brand-voice 분석
```
1. 정직함 검증: productInfo와 generatedContent 비교
   - 완벽 일치 = PASSED
   - 90% 이상 = PASSED (추측 표현 <2개)
   - 90% 미만 = WARNING
   - 근거 불명확 = FAILED

2. 제주와 기술 검증: 핵심 단어 검색
   - 제주 단어 있음 + 기술 단어 있음 = PASSED
   - 하나만 있음 = WARNING
   - 둘 다 없음 = FAILED

3. 일상 함께함 검증: 구체성 분석
   - 일상 표현 2개+ + 시나리오 있음 = PASSED
   - 일상 표현 1개 또는 시나리오 1개 = WARNING
   - 둘 다 없음 = FAILED
```

### Step 5: 종합 점수 계산
```
의료 표현: FAILED = -40점 | WARNING = -15점 | PASSED = 0점
과장 표현: FAILED = -40점 | WARNING = -15점 | PASSED = 0점
신조어:    FAILED = -20점 | WARNING = -10점 | PASSED = 0점
brand-voice: 각 항목당
  PASSED = +10점
  WARNING = +5점
  FAILED = -10점

기본 점수: 100점
최종 점수 = 100 + (각 항목별 점수)

점수 범위:
- 85점 이상: APPROVED
- 50~84점: NEEDS REVISION
- 50점 미만: REJECTED
```

### 🔍 검증 체크 (최종 배포 전 필수)

- [ ] "건강"이 일상적 맥락 (가족 밥상)에서만 사용됨?

- [ ] "최고", "기적", "유일", "세상에 하나뿐" 없음?
- [ ] "모두", "누구나", "확실히" 같은 절대성 표현 없음?
- [ ] "완벽", "무결", "대박" 없음?
- [ ] 모든 비교가 객관적 수치 기반?

**신조어 & 마케팅**
- [ ] "슈퍼푸드", "미라클", "마법" 없음?
- [ ] 근거 없는 신조어 없음?
- [ ] 마케팅 과장 용어 없음?

**brand-voice**
- [ ] 모든 수치가 제품정보와 일치?
- [ ] "제주" 또는 "기술/전통" 언급 있음?
- [ ] "당신", "우리 가족", "매일" 같은 일상 표현 있음?
- [ ] 따뜻하고 공감하는 톤?
