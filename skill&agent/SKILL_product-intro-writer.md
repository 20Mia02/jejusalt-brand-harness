## 1. Skill의 역할

제주소금의 웹앱 "제품 추천 엔진"의 **백엔드 카피 생성자**

이 Skill은 입력된 제품 정보(카테고리, 캐릭터, 제품명, 제품 스펙, 영상유형)를 받아서, **brand-voice.md의 3원칙을 지키면서** 다음을 자동으로 생성합니다:

- 캐릭터와 제품을 연결하는 스토리텔링 텍스트
- 제품의 핵심 특징 (근거 수치 포함)
- SNS 공유용 짧은 캡션
- 온라인 몰(쿠팡, 마켓컬리) 상품 설명

즉, **"한 번의 입력으로 여러 채널(숏폼 영상, SNS, 전자상거래)에 쓸 수 있는 제품 소개 카피가 자동으로 생성되는" 에이전트**입니다.

## 2. 입력 (Input) 명세

### 입력 데이터 구조 (JSON)

```javascript
{
  // 필수 필드
  "category": "식품|뷰티|헬스케어",
  "character": "결이|용암이|해수|미내|현무|가마할방|불이|한라 또는 사용자 정의 캐릭터명",
  "productName": "제주용암프리미엄솔트",
  "productInfo": "나트륨 24.1g/100g, 마그네슘 6,370mg/100g, 제주 청정 인증, 70년 전통 기술...",
  
  // 선택 필드
  "keywords": ["프리미엄", "건강", "가족"],  // 사용자가 강조하고 싶은 키워드
  "videoType": "캐릭터소개|제품스토리|일상밥상 또는 동적으로 추가된 영상유형"
}
```

### 입력 필드 상세

| 필드명 | 타입 | 필수 | 설명 | 예시 |
|--------|------|------|------|------|
| **category** | String | ✅ 필수 | 사업 영역 (식품/뷰티/헬스케어) | "식품" |
| **character** | String | ✅ 필수 | brand-voice.md의 8개 캐릭터 또는 사용자 정의 | "용암이", "커스텀_해양생명" |
| **productName** | String | ✅ 필수 | 제품 공식명 | "제주용암프리미엄솔트" |
| **productInfo** | String | ✅ 필수 | 제품 상세 정보 (스펙, 특징, 인증 등) | "나트륨 24.1g/100g, 마그네슘 6,370mg/100g, ..." |
| **keywords** | Array[String] | ⚪ 선택 | 강조할 핵심 키워드 (1~3개) | ["프리미엄", "건강"] |
| **videoType** | String | ⚪ 선택 | 영상 유형 (없으면 기본값: "제품스토리") | "캐릭터소개", "일상밥상" |

## 3. 출력 (Output) 명세

### 출력 형식 (마크다운)

```markdown
## [카테고리] | [캐릭터명]과 함께하는 [제품명]

## 이 영상이 담은 이야기
(1~2문단: 카테고리와 캐릭터, 영상유형, 제품 정보에 맞는 구체적인 이야기)

## 제품 핵심
- (제품 정보에서 추출한 핵심 수치 설명)
- (제주 청정성·안전성·자연성 또는 카테고리별 특성)
- (사용 대상이나 활용 방식)

## 추천 사용법
(일상 시나리오, 구체적인 상황을 포함한 사용 방법)

## SNS 캡션
(영상을 공유할 때 바로 쓸 수 있는 짧은 문구, 감정적 공감 중심 — 정확히 1줄)

## 온라인 몰 상품 설명
(쿠팡·마켓컬리에 그대로 복사-붙여넣기 가능한 간결한 설명 — 3~4줄)
```

### 출력 필드 상세

| 섹션 | 분량 | 목적 | 톤 |
|------|------|------|-----|
| **제목** | 1줄 | 영상 타이틀 | 명확하고 우아함 |
| **이 영상이 담은 이야기** | 1~2문단 | 영상 개요 & 감정 전달 | 따뜻하고 공감하는 톤 |
| **제품 핵심** | 2~3개 불릿 | 핵심 정보 전달 | 근거 있고 정직함 |
| **추천 사용법** | 1~2줄 | 구체적 활용 시나리오 | 일상적이고 친근함 |
| **SNS 캡션** | 정확히 1줄 | 빠른 공유와 공감 | 감정적이고 간결함 |
| **온라인 몰 설명** | 3~4줄 | 구매 결정 지원 | 명확하고 신뢰감 있음 |

## 4. 핵심 특징 (Core Features)

### 4-1. 카테고리별 톤 변화

#### 🍚 식품 (관광상품 중심)
- **핵심 톤**: "일상 밥상", "가족", "함께", "매일"
- **초점**: 나트륨/미네랄 수치, 제주 청정성, 가족 건강
- **예시 표현**: "할머니의 밥상", "모든 밥에 올려", "함께하는 매일"
- **부대 감정**: 따뜻함, 신뢰, 포근함

#### 💄 뷰티 (체험 기반)
- **핵심 톤**: "자기관리", "자연유래", "미니멀", "정성"
- **초점**: 멜로시라 함유, 미네랄 보습, 부드러운 사용감
- **예시 표현**: "정성스러운 케어", "주 1~2회의 시간", "자연이 주는 보살핌"
- **부대 감정**: 우아함, 자기애, 신비로움

#### 💚 헬스케어 (웰니스 중심, 중기 대비)
- **핵심 톤**: "웰니스", "과학적 근거", "신뢰", "건강한 삶"
- **초점**: 미네랄 함량, 순도, 과학적 검증
- **예시 표현**: "매일 아침의 습관", "확실한 품질", "건강한 선택"
- **부대 감정**: 안정감, 신뢰, 책임감

### 4-3. 영상유형별 강조점

#### 🎬 캐릭터소개 (Character Introduction)

**목적**: 캐릭터 자체에 대한 소개, "이 캐릭터가 당신에게 뭔가를 해주겠다"는 의도 전달

**강조 포인트**:
- 캐릭터가 누구인가? (역할, 특징, 성격)
- 이 캐릭터가 당신을 위해 무엇을 할 것인가?
- 함께하면 어떤 변화가 올까?

**톤**: 친근하면서도 신뢰감 있게

**예시**: "결이는 작지만 확실한 변화를 만들어요. 당신의 밥상에 올라와서..."

---

#### 🏠 제품스토리 (Product Story)

**목적**: 제품이 어디서 왔는가, 어떻게 만들어졌는가 설명

**강조 포인트**:
- 제주와 기술의 만남 (40만년 화산지형 + 70년 연구)
- 제품이 만들어지는 과정의 정성
- "이 제품의 특별함"을 왜 중심으로

**톤**: 경외심과 신뢰감을 섞은 톤

**예시**: "70년을 제주 바다에서 지켜온 해수가 당신의 밥상에 올라가는 날..."

---

#### 🍚 일상밥상 (Daily Life Scenario) 또는 기타 시나리오

**목적**: 실제 사용 장면, 구체적인 상황 전달

**강조 포인트**:
- 실제 사용 장면 (아침 밥, 저녁 반찬, 아이 밥상 등)
- "당신의 일상에 어떻게 녹아들 것인가"
- 구체적인 상황과 감정

**톤**: 따뜻하고 친근한 일상 톤

**예시**: "아침 밥을 담아낼 때, 저녁 국을 끓일 때, 모든 밥상에 올려보세요..."

## 5. 금지 사항 (Absolutely Forbidden)

### ❌ 의료/효능 표현 금지 (식품표시광고법 위반)

이것들은 절대 포함하면 안 됩니다:
- "혈압을 낮춘다"
- "혈액순환을 개선한다"
- "염증을 치유한다"
- "피부 질환을 치료한다"
- "효과가 있다" (의료적 의미로)
- "몸에 좋다" (의학적 주장으로 해석될 여지가 있으면 X)

**대신 사용할 표현**:
- "마그네슘 6,370mg 함유" (사실 전달)
- "미네랄 보습" (기능 설명)
- "나트륨은 낮추고 미네랄은 높였습니다" (특징 설명)

---

### ❌ 근거 없는 신조어 금지

## 7. brand-voice.md 3원칙 (필수 준수)

### 원칙 1️⃣: 정직하게, 과장 없이

**의미**: 근거 있는 표현만 사용

**실행 방법**:
- 제품 정보에서 추출한 수치만 언급
- "~일 가능성이 있다" 같은 추측 표현 X
- 제품이 할 수 없는 것은 절대 말하지 않기

**체크**:
- [ ] 모든 주장에 근거(수치/인증/논문)가 있는가?
- [ ] "아마도", "가능할 것", "일수도" 같은 표현은 없는가?

---

### 원칙 2️⃣: 제주와 기술의 만남

**의미**: 자연과 과학의 조화를 항상 강조

**실행 방법**:

## 9. 검증 체크리스트

### 🔍 작성 체크 (필수)

**구조 확인**
- [ ] 제목이 "[카테고리] | [캐릭터]과 함께하는 [제품명]" 형식인가?
- [ ] 6개 섹션(이야기/핵심/사용법/캡션/몰 설명)이 모두 있는가?

**내용 확인**
- [ ] "이 영상이 담은 이야기"에 **영상유형이 반영**되었는가?
  - 캐릭터소개: "이 캐릭터가 뭔가를 해주겠다"는 내용
  - 제품스토리: "어디서 왔고, 어떻게 만들어졌는가"
  - 일상밥상: "실제 사용 장면과 구체적 상황"
- [ ] 제품 정보에서 추출한 **핵심 수치가 정확**한가?
- [ ] 키워드가 **자연스럽게 포함**되었는가? (제목, 이야기, 또는 강조점)

**톤 확인**
- [ ] **카테고리와 캐릭터의 톤이 일치**하는가?
  - 식품+용암이 = 따뜻하고 포근한 톤
  - 뷰티+해수 = 정성스럽고 우아한 톤

  - ✅ 정직함 (근거 있는 표현만)
  - ✅ 제주+기술의 만남
  - ✅ 일상 속 소소한 함께함

**금지 사항 확인**
- [ ] 의료 표현 없는가? ("효과가 있다" "혈압을 낮춘다" 등)
- [ ] 근거 없는 과장 없는가? ("최고" "기적" "유일무이" 등)
- [ ] 근거 없는 신조어 없는가? ("슈퍼푸드" "미라클" 등)

**기술 요구사항**
- [ ] SNS 캡션은 **정확히 1줄**인가?
- [ ] 온라인 몰 설명은 **3~4줄**로 간결한가?

## 11. 주의사항 & 팁

### 🎯 특별히 신경 쓸 점

**카테고리 변경 시 톤 조정**
- 같은 제품이어도 식품/뷰티/헬스케어로 분류되면 톤이 달라져야 합니다.
- 예: "제주용암솔트" → 식품은 "가족 밥상"으로, 뷰티는 "피부 정성"으로

**캐릭터 변경 시 관점 변화**
- 같은 제품이어도 캐릭터가 바뀌면 설명 각도가 달라집니다.
- 예: 용암이(아버지) vs 해수(우아한 여성)는 다른 초점으로 같은 제품을 설명

**영상유형 미지정 시 기본값**
- videoType을 입력하지 않으면 "제품스토리"를 기본값으로 사용합니다.

---

### 💡 좋은 결과물의 특징

✅ **읽으면서 감정이 느껴진다**
- 단순 정보 전달이 아니라, 따뜻함/신뢰감/우아함이 흐른다

✅ **구체적이다**
- "좋다" X, "나트륨 24.1g, 마그네슘 6,370mg" O
- "아침밥" O, "밥을 먹을 때" X

✅ **논리가 일관된다**
- 제주 + 기술 + 일상이 자연스럽게 연결된다

✅ **바로 쓸 수 있다**
- SNS 캡션은 복사-붙여넣기 가능
- 몰 설명도 최소 수정만으로 게시 가능
