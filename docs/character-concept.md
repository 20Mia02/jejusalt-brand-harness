# 제주소금 8개 캐릭터 디자인 시스템 (v2 — 완전 리디자인)

기존 8개 캐릭터(결이/한라/용암이/해수/미내/현무/가마할방/불이)의 이름과 세계관은 유지하면서,
스타성·3D 영상화 적합성·성별 표현·브랜드 정체성·캐릭터 간 일관성을 강화한 리디자인 스펙이다.

`config.json`(`backend/utils/config-loader.js`의 `getDefaultConfig().brand`)의
`characterTypeSystem` / `characterStyleGuideline` / `characterCommonMotif` / `characterColorPalette`
필드와 `characters` 배열이 이 문서를 코드로 반영한 것이므로, 캐릭터 설정을 바꿀 때는 반드시
이 문서와 config를 함께 업데이트한다. `character-creator-agent`(신규 커스텀 캐릭터 생성 AI)도
이 문서의 4가지 타입 분류 규칙을 시스템 프롬프트로 전달받아 따른다.

---

## PART 1. 통일 디자인 시스템

### 1. 캐릭터 4가지 타입

| 타입 | 상징 | 색상 계열 | 형태 | 성격 |
|---|---|---|---|---|
| **SALT** (소금결정) | 결정체, 순수함, 작지만 강함 | 밝은 파랑 `#00AEEF` / `#0088CC` | 기하학적, 각진 모서리 | 활발, 밝음, 에너지, 희망 |
| **LAVA** (용암해수) | 화산 활동, 40만 년, 깊이, 신뢰 | 어두운 파랑/검정 `#0D1B2A` / `#1A3A52` | 유기적, 부드러운 곡선 | 신뢰감, 보호, 안정, 지혜 |
| **MINERAL** (미네랄) | 마그네슘, 자연미, 우아함, 프리미엄 | 중간 톤 (보라/청록 포인트) | 세련된 곡선, 액세서리 강조 | 우아함, 배려, 정교함, 감정 깊이 |
| **FIRE** (불/에너지) | 열정, 변환, 함께함, 긍정 | 따뜻한 톤 (노랑/주황/빨강) | 역동적, 움직임 강조 | 에너지, 공유, 긍정, 격려 |

캐릭터는 이 중 1~2개 타입에 속하며, 두 타입을 조합할 경우 주 타입의 색/형태를 우선한다.

### 2. 공통 설계 규칙

**크기 & 프로포션** — 손가락 첫마디 크기(귀여움+존재감), 머리 40~50%(표정 강조), 눈은 머리의
20~30%, 목은 최소한만, 팔은 짧고 굵게(튼튼함), 다리는 움직임이 명확한 형태.

**눈 (모든 캐릭터 통일)** — 큰 검정 동공 + 좌상단 흰색 하이라이트 + (선택) 색상 홍채 + 검은
테두리. 표정별 변형: 웃음(ㄷ자/^), 공감(부드러운 원, 각도 변화), 놀람(○ 최대), 신뢰(● 정상),
슬픔(ㅜ). 눈 언어를 통일해 모든 캐릭터가 "같은 세계관"임을 각인시킨다.

**입 (타입별 차이)** — 큰 입 + 검정 테두리는 공통, 색상만 타입별로: SALT=빨강/주황,
LAVA=짙은 색, MINERAL=분홍, FIRE=노랑/주황.

**색상 팔레트** — 메인(바디): SALT `#00AEEF`, LAVA `#0D1B2A`/`#1A3A52`, MINERAL/FIRE는 캐릭터별
개별 지정. 보조(액세서리): 분홍 `#FF69B4`/`#FFB6C1`, 노랑 `#FFD700`/`#FFA500`, 초록
`#90EE90`/`#3CB371`, 흰색 `#FFFFFF`(하이라이트), 검정 `#000000`(테두리).

**재질/텍스처** — SALT는 투명한 광택(하이라이트+밝은 모서리선), LAVA/MINERAL은 거친 자연미
(음영 변화, 정적 크리스탈 무늬), FIRE는 부드럽고 따뜻함(곡선+따뜻한 배경 음영). 3D(Higgsfield)
호환을 위해 항상 단순하게 유지한다.

**표정 4가지 기본 (+최대 2가지 선택)**
1. 행복/웃음 — 눈 ㄷ자/^, 입 큰 U자
2. 공감/따뜻함 — 눈 부드러운 원, 입 작은 미소
3. 놀람/에너지 — 눈 ○, 입 O
4. 신뢰/차분 — 눈 ●, 입 일자선/미소
5. (선택) 슬픔/공감 — 눈 ㅜ, 입 U자
6. (선택) 신비로움 — 눈 반짝임 + 특수 효과

**동작 기본 3가지 (+캐릭터별 1~2가지)** — 회전(자신감), 손 제스처(설명/교감), 고개 기울임
(호기심/공감)은 모든 캐릭터 공통. 추가: 점프/에너지(SALT·FIRE), 우아한 움직임(MINERAL),
보호/포옹 제스처(LAVA).

**액세서리** — 캐릭터 정체성 강화 + (필요 시) 성별 표현 강화 + 3D로 단순하게 표현 가능 +
움직임 가능한 형태(리본/귀걸이 등). 모자/머리 장식은 캐릭터 상징, 리본/넥타이는 성별 표현.

## PART 2. 8개 캐릭터 상세 설계

### 1. 결이 (Salt Crystal) — 밝은 남아
- **성별/나이/타입**: 남성, 10대 초반, SALT
- **역할/성격**: 당찬 소년 · 도전적, 에너지 넘침, 순수함·희망·새로운 시작의 상징
- **외형**: 밝은 파랑 `#00AEEF` 정육면체(모서리 약간 둥글게), 파란 모자 또는 뾰족한 소금결정
  머리, 큰 검정 눈 + 흰 하이라이트, 큰 웃음 + 빨간 혀, 빨간 물방울 귀, 짧고 굵은 팔다리,
  몸 모서리에 은은한 크리스탈 무늬
- **음성**: 밝고 맑은 소년(7~10세), "~해!", "좋아!", "함께해봐!", 끝을 올려 발음
- **표정**: 웃음(ㄷ자/큰U), 공감(부드러움/작은미소), 놀람(○/O), 신뢰(●/일자)
- **동작**: 손 흔들기, 점프, 회전, 포인트
- **Higgsfield 프롬프트**:
  ```
  캐릭터: 결이 (밝은 남아) — 정육면체, 밝은 파랑 #00AEEF, 모서리 약간 부드러움, 광택감
  파란 모자 또는 뾰족한 머리, 큰 검정 눈, 흰 하이라이트, 큰 웃음, 빨간 혀, 빨간 물방울 귀
  짧은 팔, 굵은 다리, 몸에 은은한 크리스탈 무늬
  표정: 웃음(ㄷ자), 공감(부드러움), 놀람(○), 신뢰(●) / 동작: 손 흔들기, 점프, 회전, 포인트
  배경: 밝은 파란 하늘 / 분위기: 밝음, 에너지, 희망 / 톤: 따뜻하면서도 강함
  ```

### 2. 한라 (Hallasan) — 신비로운 여성 (할머니)
- **성별/나이/타입**: 여성, 60대 이상, LAVA
- **역할/성격**: 신비로운 지혜자 · 신비로움, 지혜, 역사, 제주의 근원
- **외형**: 둥근 산 모양, 어두운 파랑 `#1A3A52`, 흰/회색 머리, 부드럽고 지혜로운 초록/밝은
  파랑 눈, 포근한 미소, 이마 주름(경험), 목걸이/스카프, 몸에 미세한 산 무늬
- **음성**: 부드럽고 깊은 할머니 목소리, "~인걸", "~은 말이야", "우리 함께 봐", 느리고 차분함
- **표정**: 웃음(가늘어짐/부드러운U), 공감(부드러움/작은미소), 신비(반짝임), 차분(명상적/일자)
- **동작**: 손 모으기, 천천한 회전, 고개 기울임
- **Higgsfield 프롬프트**:
  ```
  캐릭터: 한라 (신비로운 할머니) — 둥근 산 모양, 어두운 파랑 #1A3A52, 거친 화산암 질감
  흰색/회색 머리, 부드럽고 지혜로운 초록/밝은 파랑 눈, 포근한 미소, 이마에 주름
  목걸이 또는 스카프, 몸에 미세한 산 무늬
  표정: 웃음(가늘어짐), 공감(부드러움), 신비(반짝임), 차분(명상적) / 동작: 손 모으기, 천천한 회전, 고개 기울임
  배경: 신비로운 밤하늘, 별빛 / 분위기: 신비로움, 지혜, 포용 / 톤: 깊이 있고 따뜻한
  ```

### 3. 용암이 (Lavaman) — 따뜻한 남성 (아버지)
- **성별/나이/타입**: 남성, 40~50대, LAVA + FIRE
- **역할/성격**: 따뜻한 아버지 · 신뢰, 보호, 기술, 따뜻함
- **외형**: 둥근 몸 + 각진 어깨, 진한 파랑 `#0D1B2A`, 검정/짙은 파란 머리, 따뜻한 갈색/어두운
  눈, 부드러운 미소, 넓은 가슴, 굵은 팔다리, 목에 스카프/앞치마(장인 느낌), 몸에 작은 불꽃 무늬
- **음성**: 낮고 따뜻한 남성 목소리, "~해줄게", "믿어봐", "같이 할거야", 천천히 신뢰감 있게
- **표정**: 웃음(가늘어짐/따뜻한U), 공감(부드러움/미소), 신뢰(●/일자), 강함(차분/일자)
- **동작**: 손 펴기, 가슴팍 터치, 천천한 회전
- **Higgsfield 프롬프트**:
  ```
  캐릭터: 용암이 (따뜻한 아버지) — 둥근 몸 + 각진 어깨, 진한 파랑 #0D1B2A, 거친 질감
  검정/짙은 파란 머리, 따뜻한 갈색/어두운 눈, 부드러운 미소, 넓은 가슴, 튼튼한 몸
  굵은 팔, 강한 다리, 목에 스카프 또는 앞치마, 몸에 작은 불꽃 무늬
  표정: 웃음(가늘어짐), 공감(부드러움), 신뢰(명확), 강함(차분) / 동작: 손 펴기, 가슴팍 터치, 천천한 회전
  배경: 따뜻한 가마 또는 해질녘 / 분위기: 따뜻함, 신뢰, 강함 / 톤: 깊이 있고 따뜻한
  ```

### 4. 해수 (Mineral) — 우아한 여성
- **성별/나이/타입**: 여성, 20~40대, MINERAL
- **역할/성격**: 우아한 자유로운 영혼 · 우아함, 미네랄, 프리미엄, 신비로움
- **외형**: 우아한 S자 곡선, 보라 `#6B4C9A` 또는 청록 `#008B8B`, 길고 우아한 머리 + 분홍 리본,
  크고 반짝이는 초록/보라 눈, 세련된 분홍 미소, 귀걸이(별/다이아몬드), 목걸이, 크리스탈 무늬
- **음성**: 부드럽고 세련된 여성 목소리, "~해요", "함께하시겠어요?", "특별해요", 느리고 우아하게
- **표정**: 미소(반짝임/세련된U), 공감(부드러움/작은미소), 신비(반짝임), 따뜻(반짝/미소)
- **동작**: 우아한 회전, 손 펼치기, 고개 살짝 기울임
- **Higgsfield 프롬프트**:
  ```
  캐릭터: 해수 (우아한 여성) — 우아한 S자 곡선, 보라색 #6B4C9A 또는 청록색, 고급스러운 질감
  길고 우아한 머리, 분홍 리본, 크고 반짝이는 초록/보라 눈, 세련된 분홍색 미소
  귀걸이(별/다이아몬드), 목걸이, 몸에 크리스탈 무늬
  표정: 미소(반짝임), 공감(부드러움), 신비(반짝임), 따뜻(따뜻함) / 동작: 우아한 회전, 손 펼치기, 고개 살짝 기울임
  배경: 신비로운 정원 또는 별빛 / 분위기: 우아함, 신비, 고급스러움 / 톤: 부드럽고 세련된
  ```

### 5. 미내 (Magnesium) — 밝은 여성 (누나)
- **성별/나이/타입**: 여성, 10대 후반~20대, SALT + FIRE
- **역할/성격**: 포용적인 누나 · 격려, 함께함, 활발함, 포용
- **외형**: 동그랗고 통통한 몸, 노랑 `#FFD700` 또는 주황 `#FF8C00`, 노랑/주황 머리 + 리본,
  크고 밝은 검정 눈 + 강한 하이라이트, 큰 웃음(빨강/주황), 짧고 통통한 팔다리, 불꽃 무늬
- **음성**: 밝고 발랄한 소녀 목소리, "~해봐!", "함께하자!", "넌 할 수 있어!", 빠르고 밝게
- **표정**: 웃음(ㄷ자/큰U), 공감(하트형/미소), 에너지(○/큰O), 격려(반짝/미소)
- **동작**: 손 흔들기, 점프, 회전, 박수
- **Higgsfield 프롬프트**:
  ```
  캐릭터: 미내 (밝은 누나) — 동그랗고 통통한 몸, 노랑/주황 #FFD700, 밝은 톤
  노랑/주황 머리, 리본, 크고 밝은 검정 눈, 강한 하이라이트, 큰 웃음(빨강/주황 입)
  짧고 통통한 팔다리, 분홍 리본 또는 활, 몸에 불꽃 무늬
  표정: 웃음(ㄷ자), 공감(하트형), 에너지(○), 격려(반짝) / 동작: 손 흔들기, 점프, 회전, 박수
  배경: 밝은 태양 또는 열정적인 배경 / 분위기: 밝음, 에너지, 따뜻함 / 톤: 발랄하고 격려적
  ```

### 6. 현무 (Basalt) — 신뢰로운 남성 (형)
- **성별/나이/타입**: 남성, 20~30대, LAVA + SALT
- **역할/성격**: 묵직한 장인 · 신뢰, 기술, 정확성, 견고함
- **외형**: 각진 어깨, 다크 파랑 `#1F3A52`, 검정 짧은 머리(단정함), 묵직한 검정/어두운 갈색 눈,
  일자선 또는 미세한 미소, 튼튼한 몸 + 강한 팔다리, 액세서리 없음(단순함), 기하학적 무늬
- **음성**: 낮고 정중한 남성 목소리, "그렇게 해", "됐어", "믿어", 짧고 정확하게, 웃음 거의 없음
- **표정**: 신뢰(●/일자), 공감(부드러움/미소), 결정(명확/일자), 안심(안정/미소)
- **동작**: 손가락 포인트, 천천한 회전, 가슴팍 터치
- **Higgsfield 프롬프트**:

## 컨셉 스케치 (Higgsfield 생성 전 임시 확인용)

`docs/character-concept-sketches/`에 8개 캐릭터의 SVG 벡터 스케치가 있다. Higgsfield로 실제
영상을 생성하기 전, 확정된 색상/형태/눈/입 스펙이 맞는지 앱 화면에서 미리 확인하기 위한
용도로 제작했으며, Supabase `character_library.reference_image_url`에도 data URI로 저장되어
있다 (`generation_seed = 'concept-sketch-v1'`로 표시해 실제 Higgsfield 생성본과 구분).
외형이 최종 승인되면 위 PART 2의 Higgsfield 프롬프트로 실제 레퍼런스 영상을 생성해
이 값을 교체한다.

## PART 3. 일관성 관리 체크리스트

**설계 단계**
- [ ] 타입 분류 (SALT/LAVA/MINERAL/FIRE, 최대 2개 조합)
- [ ] 색상 팔레트 준수 (`characterColorPalette`에 정의된 색만 사용)
- [ ] 크기 통일 (손가락 첫마디, 약간의 변동 허용)
- [ ] 눈 구조 통일 (검정 동공 + 흰 하이라이트)
- [ ] 표정 4가지 기본 + 최대 2가지 추가
- [ ] 동작 3~4가지 (회전/손 제스처/고개 기울임 필수)
- [ ] 액세서리로 정체성/성별 강화
- [ ] 음성 톤 (타입별 공통 + 캐릭터별 개성)

**Higgsfield 생성 단계** (실제 영상 생성 시 적용)
- [ ] 위 프롬프트 템플릿 준수
- [ ] 색상 코드 정확히 명시
- [ ] 텍스처 3D 호환 (복잡하지 않게)
- [ ] 표정 4종 각각 다르게 명확히 표현
- [ ] 배경은 제주 테마로 일관

**QA 단계**
- [ ] 스타성 (한눈에 인식 가능)
- [ ] 제주소금 정체성 (소금/용암/미네랄/불 상징 명확)
- [ ] 성별 차이 명확 (남성 4명: 결이·용암이·현무·불이 / 여성 4명: 한라·해수·미내·가마할방)
- [ ] 다른 캐릭터와 조화 (통일된 디자인 언어)
- [ ] `compliance-reviewer-agent` / `post-generation-qa-agent` 통과
