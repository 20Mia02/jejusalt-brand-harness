## 1. Skill의 역할

제주소금 웹앱의 **제품 정보 자동 분석자**

사용자가 입력한 제품 정보 텍스트를 자동으로 분석하여, product-intro-writer와 character-generator가 바로 사용할 수 있는 메타데이터(JSON)를 생성하는 에이전트입니다.

즉, **"자유 형식의 제품 정보 텍스트 → 정형화된 JSON 메타데이터"로 자동 변환하는 NLP 분석기**입니다.

---

## 2. 입력 (Input) 명세

### 입력 데이터 구조 (JSON)

```javascript
{
  "productName": "제주용암프리미엄솔트",
  "productInfo": "나트륨 24.1g/100g (일반 소금 대비 40% 감소), 마그네슘 6,370mg/100g, 규소 90mg/100g, 제주 청정 인증, 70년 전통 기술로 생산",
  "keywords": ["프리미엄", "건강", "가족"]  // 선택사항
}
```

### 입력 필드 상세

| 필드명 | 타입 | 필수 | 설명 | 예시 |
|--------|------|------|------|------|
| **productName** | String | ✅ 필수 | 제품 공식명 | "제주용암프리미엄솔트" |
| **productInfo** | String | ✅ 필수 | 제품 정보 설명 (자유 형식) | "나트륨 24.1g/100g..." |
| **keywords** | Array[String] | ⚪ 선택 | 추가 키워드 (1~5개) | ["프리미엄", "건강"] |

## 4. 분석 로직

### Step 1: 키워드 추출

**목표**: productInfo에서 핵심 단어들을 추출하고 분류

**프로세스**:
1. 제품명 + productInfo + keywords 모두 수집
2. 텍스트를 토큰화하여 단어 추출
3. 불용어(the, a, 을, 를 등) 제거
4. 각 단어를 긍정/중립/부정으로 분류

**추출할 주요 단어 카테고리**:
```
수치 관련: g/100g, mg, %, 개, 개월 등
특징 관련: 프리미엄, 전통, 자연, 부드러움 등
기술 관련: 기술, 기술력, 인증, 과학적 등
감정 관련: 정성, 따뜨함, 포근함, 우아함 등
활동 관련: 운동, 활기, 에너지, 활동 등
```

**예시**:
```
입력: "나트륨 24.1g/100g (일반 소금 대비 40% 감소), 마그네슘 6,370mg/100g, 
      규소 90mg/100g, 제주 청정 인증, 70년 전통 기술로 생산"

추출된 핵심 단어:
- 수치: [24.1, 40, 6370, 90, 70]
- 특징: [나트륨, 마그네슘, 규소, 제주, 청정, 전통]
- 기술: [기술, 인증]
- 지역: [제주]
```

---

### Step 2: 카테고리 매핑

**목표**: 제품이 어느 사업 영역에 속하는지 자동 분류

**분류 규칙**:

| 키워드 | 카테고리 |
|--------|---------|
| 소금, 밥, 국, 반찬, 양념, 조리 | 식품 |
| 피부, 비누, 스크럽, 케어, 마스크, 토너, 에센스 | 뷰티 |
| 건강, 미네랄, 영양, 웰니스, 에너지, 면역, 나트륨 | 헬스케어 |

**로직**:
```
1. 각 카테고리의 키워드 매칭 점수 계산
2. 점수 >= 2 이면 해당 카테고리 포함
3. 여러 카테고리가 매칭되면 모두 포함 (최대 3개)
4. 매칭 안 되면 "분류 불가" → 신뢰도 감소
```

**예시**:
```
제주용암프리미엄솔트:
- 식품 점수: "소금"(1) + "양념"(1) = 2 → ✅ 식품 포함
- 뷰티 점수: 0 → ❌ 제외
- 헬스케어 점수: "건강"(1) + "미네랄"(1) + "나트륨"(1) = 3 → ✅ 헬스케어 포함
- 결과: ["식품", "헬스케어"]
```

---

### Step 3: 나이대 추정

**목표**: 타겟 연령대를 추정

**추정 규칙**:

| 키워드 | 나이대 | 근거 |
|--------|--------|------|
| 아이, 아기, 아들, 딸, 엄마, 부모 | 20~40대 | 자녀가 있는 연령 |
| 가족, 밥상, 함께, 일상, 매일 | 40~60대 | 가족 중심 사고 |
| 운동, 활기, 에너지, 활동적, 파워 | 20~35대 | 에너지 추구 |
| 노화, 주름, 탄력, 항노화, 개선 | 40~60대+ | 노화 관심 |
| 피부, 관리, 정성, 미니멀, 감성 | 20~40대 여성 | 자기관리 중심 |
| 신뢰, 안정, 책임, 기술 | 40~60대 | 신뢰성 중시 |
| 역사, 전통, 세대, 오래 | 40~60대+ | 역사 가치 |

**로직**:
```
1. productInfo에서 나이대 관련 키워드 검색
2. 가장 많이 매칭되는 나이대 선택
3. 명확한 나이대 키워드 없으면 "무관"
4. 여러 나이대가 매칭되면 가장 강한 신호 우선
```

**예시**:
```
제주용암프리미엄솔트:
- "가족 밥상" 키워드 → 40~60대 신호 +3
- "건강" 키워드 → 40~60대 신호 +2
- "전통 기술" 키워드 → 40~60대 신호 +2
- 합계: 40~60대가 가장 강한 신호
- 결과: ["40~60대"]
```

---

### Step 4: 성별 추정

**목표**: 타겟 성별을 추정

**추정 규칙**:

| 키워드 | 성별 | 근거 |
|--------|------|------|
| 피부, 미용, 뷰티, 케어, 스킨 | 여성 우세 | 뷰티는 여성 중심 |
| 가족, 밥상, 요리, 반찬, 국 | 무관 | 남녀 모두 관련 |
| 근육, 운동, 파워, 에너지 | 남성 우세 | 피트니스 중심 |
| 건강, 영양, 웰니스, 일상 | 무관 | 남녀 모두 관심 |

**로직**:
```
1. 성별 특화 키워드 검색
2. 여성 키워드 점수 vs 남성 키워드 점수
3. 차이가 2 이상이면 해당 성별, 아니면 "무관"
4. 명확한 성별 신호 없으면 "무관"
```

**예시**:
```
제주용암프리미엄솔트:
- 여성 키워드: 0
- 남성 키워드: 0
- 무관 키워드: "가족"(1), "일상"(1) = 2
- 결과: ["무관"]

제주용암솔트비누 (뷰티):
- 여성 키워드: "피부"(1) + "비누"(1) = 2
- 남성 키워드: 0
- 차이 >= 2 → 여성 우세
- 결과: ["여성"]
```

---

### Step 5: 대상 추정

**목표**: 고객 유형과 사용 목적을 추정

**대상 분류**:

| 대상 | 핵심 키워드 | 예시 |
|------|-----------|------|
| 가족밥상 | 가족, 밥상, 함께, 아이, 엄마 | "우리 가족 밥상" |
| 개인케어 | 피부, 개인, 자기, 나 혼자, 관리 | "내 피부 케어" |
| 건강관심층 | 건강, 영양, 웰니스, 미네랄, 나트륨 | "건강한 식습관" |
| 운동애호가 | 운동, 활기, 에너지, 활동, 피트니스 | "운동 후 회복" |
| 관광객/선물 | 여행, 관광, 선물, 기념, 기념품 | "제주 여행 기념품" |
| 감성가/미니멀 | 감성, 정성, 미니멀, 자신감, 의도적 | "당신을 위한 정성" |

**로직**:
```
1. 각 대상의 핵심 키워드 매칭 점수 계산
2. 점수 >= 2 이면 해당 대상 포함
3. 최대 3개까지 포함 가능
4. 명확한 대상 없으면 기본값 할당
```

**예시**:
```
제주용암프리미엄솔트:
- 가족밥상: "가족"(1) + "밥상"(1) = 2 → ✅
- 건강관심층: "건강"(1) + "미네랄"(1) + "나트륨"(1) = 3 → ✅
- 개인케어: 0 → ❌
- 결과: ["가족밥상", "건강관심층"]
```

### Step 6: 캐릭터 매칭

**목표**: 가장 적합한 브랜드 캐릭터 추천 (최대 2개)

**캐릭터 선택 규칙**:

| 캐릭터 | 매칭 키워드 | 우선순위 |
|--------|-----------|---------|
| 결이 | 변화, 시작, 희망, 새로운, 시작 | 신제품 강조 |
| 용암이 | 가족, 함께, 밥상, 포근, 신뢰, 일상 | 가족 밥상 |
| 해수 | 정성, 자연, 우아, 비누, 피부, 정제, 미니멀 | 뷰티/정성 |
| 미내 | 응원, 공감, 함께, 밝음, 친구, 피부 | 응원/케어 |
| 현무 | 신뢰, 건강, 안정, 기술, 책임, 인증 | 신뢰/과학 |
| 가마할방 | 전통, 70년, 기술, 역사, 세대, 함께 | 전통/역사 |
| 불이 | 활기, 에너지, 즐거움, 활동, 재미 | 웰니스/활기 |
| 한라 | 역사, 제주, 신화, 자연, 장기관점 | 제주/역사 |

**로직**:
```
1. 각 캐릭터의 매칭 키워드 스코어 계산
2. 스코어 >= 1 이면 후보 캐릭터
3. 스코어가 가장 높은 2개 선택
4. 같은 스코어면 우선순위 고려
5. 최소 1개는 무조건 선택 (스코어 0이어도)
```

**예시**:
```
제주용암프리미엄솔트:
- 용암이: "가족"(1) + "밥상"(1) + "일상"(1) = 3 → 1순위
- 현무: "신뢰"(1) + "건강"(1) + "기술"(1) = 3 → 2순위
- 가마할방: "70년"(1) + "기술"(1) = 2
- 결과: ["용암이", "현무"]
```

---

### Step 7: 강조점 추출

**목표**: 콘텐츠에서 강조할 주요 포인트 추출 (3~5개)

**강조점 분류**:

| 강조점 | 핵심 키워드 | 의미 |
|--------|-----------|------|
| 건강 | 건강, 영양, 미네랄, 나트륨, 웰니스 | 건강 가치 |
| 신뢰 | 신뢰, 인증, 안전, 제주, 청정, 확실 | 신뢰성 |
| 기술 | 기술, 기술력, 과학, 전통, 70년, R&D | 기술력 |
| 자연성 | 자연, 유래, 생태, 정제, 청정, 미네랄 | 자연성 |
| 일상 | 일상, 밥상, 매일, 함께, 평범한 | 일상성 |
| 감정 | 정성, 따뜻, 포근, 우아, 감성, 공감 | 감정 |
| 자기관리 | 케어, 관리, 미, 자신감, 정성 | 자기관리 |
| 프리미엄 | 프리미엄, 고급, 특별, 차별, 한정 | 프리미엄 가치 |

**로직**:
```
1. 각 강조점의 키워드 매칭 점수 계산
2. 점수 > 0 인 강조점들 선택
3. 점수 순서로 내림차순 정렬
4. 상위 3~5개 선택
5. 정확히 3~5개가 되도록 조정
```

**예시**:
```
제주용암프리미엄솔트:
- 신뢰: "인증"(1) + "제주"(1) + "확실"(1) = 3 점
- 건강: "건강"(1) + "나트륨"(1) + "미네랄"(1) = 3 점
- 기술: "기술"(1) + "70년"(1) = 2 점
- 자연성: "제주"(1) + "청정"(1) = 2 점 (중복 제거)
- 일상: "밥상"(1) + "매일"(1) = 2 점
- 정렬: 신뢰(3) > 건강(3) > 기술(2) > 자연성(1) > 일상(1)
- 결과: ["신뢰", "건강", "기술"] (상위 3개)
```

### Step 8: 신뢰도 계산

**목표**: 분석 결과의 정확성을 0.0~1.0 점수로 평가

**신뢰도 계산 공식**:
```
기본 점수: 0.5
+ 명확한 수치 개수 * 0.1 (최대 0.3)
+ 인증/특징 명시 * 0.15 (최대 0.15)
+ 기술/기술력 명시 * 0.1 (최대 0.1)
+ keywords 제공 여부 * 0.1 (최대 0.1)
- 모호한 표현 개수 * 0.05 (최소 0.0)
= 최종 신뢰도 (0.0~1.0)
```

**신뢰도 수준 분류**:

| 신뢰도 범위 | 수준 | 의미 | 권장사항 |
|-----------|------|------|---------|
| 0.85~1.0 | ⭐⭐⭐⭐⭐ 매우 높음 | 구체적 근거 충분 | 바로 사용 가능 |
| 0.65~0.84 | ⭐⭐⭐⭐ 높음 | 부분적 근거 | 약간의 추가 정보 권장 |
| 0.45~0.64 | ⭐⭐⭐ 중간 | 제한적 정보 | 추가 정보 권장 |
| 0.25~0.44 | ⭐⭐ 낮음 | 매우 모호 | 재입력 강력 권장 |
| 0.0~0.24 | ⭐ 매우 낮음 | 분석 불가능 | 재입력 필수 |

**신뢰도 계산 항목**:

```
가산 항목:
+ 명확한 수치 (g/100g, mg, % 등)
  - 1~2개: +0.1
  - 3~4개: +0.2
  - 5개 이상: +0.3

+ 인증 정보 명시
  - 제주 청정 인증: +0.1
  - 정부 인증: +0.05
  - 한 개 이상: +0.15 (최대)

+ 기술/기술력 언급
  - "기술", "전통", "70년" 등: +0.1

+ keywords 제공
  - 2개 이상: +0.1

감산 항목:
- 모호한 표현 ("좋은", "우수한", "최고의" 근거 없이)
  - 1~2개: -0.05
  - 3개 이상: -0.1

- 근거 없는 주장
  - 1~2개: -0.1
  - 3개 이상: -0.2
```

**예시 1 (높은 신뢰도)**:
```
입력: "나트륨 24.1g/100g, 마그네슘 6,370mg/100g, 규소 90mg/100g, 
      제주 청정 인증, 70년 전통 기술"

계산:
- 기본: 0.5
- 명확한 수치 3개: +0.2
- 인증 정보: +0.15
- 기술 명시: +0.1
- 모호한 표현: 0
- 최종: 0.5 + 0.2 + 0.15 + 0.1 = 0.95
→ 신뢰도: 0.95/1.0 (매우 높음)
```

**예시 2 (낮은 신뢰도)**:
```
입력: "제주에서 만든 좋은 비누입니다"

계산:
- 기본: 0.5
- 명확한 수치: 0
- 인증 정보: 0
- 기술 명시: 0
- 모호한 표현 ("좋은"): -0.05
- 근거 없는 주장: -0.1
- 최종: 0.5 - 0.05 - 0.1 = 0.35
→ 신뢰도: 0.35/1.0 (낮음, 재입력 권장)
```
