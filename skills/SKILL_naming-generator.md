# SKILL_naming-generator (네이밍 제너레이터)

## 📌 목적

Skill_02에서 완성된 120초 시나리오와 최종 캐릭터를 바탕으로:
1. **제품명 자동 생성** (3개 선택지 제시)
2. **캐릭터명 자동 생성** (새로운 캐릭터가 있으면)
3. **콘텐츠명 자동 생성** (영상 제목/캠페인명)
4. **마케터가 각 항목을 선택 가능**
5. **최종 패키지 통합** (모든 선택 확정)

## 🎯 네이밍 3가지 카테고리

### 1️⃣ 제품명 (Product Name)

**정의**: 실제 판매될 제품의 이름

**특징**:
- 2-4글자 권장 (기억하기 쉬움)
- 제주소금 세계관 기반
- 가격대/타겟을 반영
- 톤 명확

**예시**:
```
- "용암빛" (프리미엄)
- "70년의 정성" (스토리 강조)
- "제주의 선물" (대중적)
```

### 2️⃣ 콘텐츠명 (Content Name)

**정의**: 영상 제목, 캠페인명, 블로그 제목

**특징**:
- 더 길 수 있음 (3-10글자)
- 스토리 기반
- 감정 전달
- 검색 최적화 고려

**예시**:
```
- "제주의 바다가 주는 따뜬한 선물"
- "40만 년 화산이 선물하는 따뜬함"
- "소금 한 알에 담긴 70년의 정성"
```

### 3️⃣ 캐릭터명 (Character Name) - 새 캐릭터만

**정의**: 새로 생성된 캐릭터의 이름

**특징**:
- 자연 요소 기반
- 제주소금 세계관과 일관성
- 역할을 암시하는 이름
- 발음하기 쉬움

**예시**:
```
- "해변지기" (바다를 지키는 존재)
- "화산이" (화산지형 상징)
- "파도꽃" (신비로움 + 우아함)
```

## 📊 점수 계산 공식 (상세)

### 4가지 점수 항목

```
총점 = 톤 일치도(0-40) + 세계관 일치도(0-30) + 기억용이성(0-20) + 차별성(0-10)
최대: 100점

1. 톤 일치도 (0-40점)
   - primary_tone과의 일치: 0-30점
   - secondary_tone과의 일치: 0-10점
   
   예: "용암빛"
   - 따뜸함 구현: 20점
   - 제주정체성 + 신비: 18점
   = 38점

2. 세계관 일치도 (0-30점)
   - 제주소금 세계관 반영: 0-20점
   - 기존 캐릭터와의 연결: 0-10점
   
   예: "용암빛"
   - 용암해수 + 결이 반영: 20점
   - 세계관과 자연스러운 연결: 10점
   = 30점

3. 기억용이성 (0-20점)
   - 글자 수 (2-4글자 권장): 0-10점
   - 발음의 쉬움: 0-10점
   
   예: "용암빛"
   - 3글자, 발음 쉬움: 18점

4. 차별성 (0-10점)
   - 기존 제품/캐릭터와의 구분: 0-5점
   - 시장에서의 차별화: 0-5점
   
   예: "용암빛"
   - 충분히 차별적: 9점
```

### 순위 결정 기준

```
90점 이상: ⭐⭐⭐ 매우 추천
80~89점: ⭐⭐ 추천
70~79점: ⭐ 가능
60~69점: 대체 옵션
```

## 💬 마케터 수정 및 최종 선택

### 수정 옵션 (5가지)

```
1. "이 중에서 선택할래" (1순위 선택)
   → 즉시 확정, 다음 단계로

2. "2순위로 바꿔줄래" (선택 변경)
   → 1순위 대신 2순위 확정

3. "다시 생성해줘" (전체 재생성)
   → SKILL이 새로운 3개 옵션 제시
   → 최대 2회까지

4. "이 부분 수정해줘" (부분 수정)
   → "더 감정적으로", "더 짧게" 등
   → SKILL이 톤 조정해서 새 옵션 제시

5. "내가 직접 만들 이름이 있어"
   → 마케터가 직접 제안
   → SKILL이 타당성 검증 후 확정
```
