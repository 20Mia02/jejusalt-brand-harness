# SKILL_character-designer (캐릭터 디자이너)

## 📌 목적

입력된 브리프를 바탕으로:
1. **기본 8개 캐릭터 중 최적 캐릭터를 "점수 기반"으로 자동 추천** (상위 2~3명)
2. **필요시 새로운 캐릭터 AI 자동 생성 + 마케터 승인 요청**
3. **마케터가 자유롭게 수정 가능** (추가/삭제/변경/역할 수정)
4. **최종 확정된 캐릭터 목록을 Agent를 통해 다음 Skill에 전달**

## 🎯 캐릭터 선택 알고리즘

### Step 1: 톤 기반 필터링 (점수: 0-40)

```
primary_tone을 기준으로 가장 높은 점수의 캐릭터 3~5개 선정

예:
- Primary tone = "따뜸함"
  → 결이(40), 가마할방(38), 불이(35) 점수 획득
```

### Step 2: 비즈니스 영역 확인 (점수: 0-30)

```
사업영역에 최적화된 캐릭터인지 확인

예:
- 식품/관광 → 결이 최고점(30)
- 뷰티/제품 → 해수 최고점(30)
- 헬스케어 → 현무 최고점(30)
```

### Step 3: 타겟 오디언스 매칭 (점수: 0-20)

```
타겟 연령, 성별, 관심사와 캐릭터 매칭

예:
- 40~60대 여성 → 결이(20), 한라(18), 가마할방(16)
```

### Step 4: 신뢰도 점수 계산 (0-100)

```
총점 = 톤 필터(40) + 비즈니스(30) + 타겟(20) + 추가(10)

90점 이상: 새 캐릭터 불필요
70~89점: 새 캐릭터 고려
70점 미만: 새 캐릭터 권장
```

### Step 5: 상위 2~3명 선정

```
점수가 높은 순서대로 상위 2~3명 선정

주인공(protagonist): 1명 (점수 최고)
조연(supporting): 1~2명 (점수 2~3위)

예외: 타겟이 "모든 연령층"이면 다양성 고려
```

## 🆕 새 캐릭터 자동 생성

### 생성 판단 기준

```
다음 중 하나라도 해당하면 생성 고려:

1. 신뢰도 점수 < 70
   → "기존 캐릭터로는 부족합니다"

2. 톤 커버리지 < 60%
   → "필요한 톤이 기본 8개에 없습니다"

3. 스토리가 매우 특수함
   → "이 특수한 상황을 위한 캐릭터가 필요합니다"

4. 마케터가 명시적으로 요청
   → "새로운 캐릭터가 필요해요"
```

### 생성 프로세스 (상세)

```
Step 1: 부족한 요소 파악
  Q: 기존 8개에서 부족한 톤은?
  Q: 필요한 역할은 (주인공/조연/카메오)?
  Q: 제주소금 세계관과의 연결 고리는?

Step 2: 새 캐릭터 개념 생성
  - 이름 제안 (2~4글자 추천)
  - 상징 제안 (자연요소 기반)
  - 역할 제안 (구체적)
  - 톤 제안 (명확)

Step 3: 기본 정보 정의
  - 성격: 3~4개 특징
  - 대사 스타일: 직접 대사 or 내레이션
  - 기본 대사 예시 2~3개
  - 기본 8개와의 관계

Step 4: 마케터에게 제안
  "이런 새로운 캐릭터를 생성하겠습니다"
  + 위의 모든 정보 표시
  + 마케터 선택/수정 대기
```

## 💬 마케터 수정 인터페이스 (구체적)

### 수정 Option 1: 캐릭터 추가

```
마케터: "새로운 캐릭터를 추가하고 싶어요"
또는: "제주의 신비로움을 더 강조하는 캐릭터가 필요해요"

Agent 동작:
  1. SKILL에 요청: "새 캐릭터 생성"
  2. AI가 개념 제시
  3. 마케터 승인/수정
  4. 최종 추가
```

### 수정 Option 2: 캐릭터 삭제

```
마케터: "한라는 필요 없어요, 삭제해줘"

Agent 동작:
  1. 해당 캐릭터 삭제
  2. 남은 캐릭터만 유지
  3. "현재 캐릭터: 결이, 가마할방" 표시
```

### 수정 Option 3: 캐릭터 변경

```
마케터: "가마할방 대신 용암이로 바꾸고 싶어"

Agent 동작:
  1. 가마할방 제거
  2. 용암이 추가
  3. 용암이의 역할 (주인공/조연) 자동 조정
```

### 수정 Option 4: 역할 수정

```
마케터: "결이를 주인공에서 조연으로 바꿔줘"

Agent 동작:
  1. 결이의 role: "protagonist" → "supporting"
  2. 새로운 주인공 필요 판정

```
