# QA Agent (Step 9) - 카테고리별 상세 검증

**버전**: v2.0 (2026.08.13)  
**목표**: Step 8(영상 생성) 완료 후 카테고리별 법적/윤리적 검증

---

## 📋 개요

Step 9는 두 가지 검증 단계로 구성됩니다:

1. **Phase 1: 자동 검증** - AI가 금지 키워드/표현 자동 스캔 (즉시 결과)
2. **Phase 2: 수동 검증** - 마케터가 체크리스트 기반 상세 검토 (3~5분)
3. **Phase 3: 최종 판정** - PASS / WARNING / REJECTED

---

## 🎯 각 카테고리별 검증 항목

### 1️⃣ 식품 (🍳 제주소금)

**총 14개 검증 항목**

#### Critical (불통과 조건)
- ❌ 의학적 효능 주장 (치료, 완치, 질병 예방 등)
- ❌ 거짓 원산지 표시
- ❌ 부정확한 영양소 함량

#### High Priority (경고 조건)
- ⚠️ 과도한 할인율 (60% 초과)
- ⚠️ 다른 제품 폄하 표현
- ⚠️ 제조 과정의 비투명성
- ⚠️ 취약층(영유아, 임산부) 주의사항 부재
- ⚠️ 환경/지속성 표현의 검증 불가

#### 마케터 수동 체크

```
□ 원산지가 실제 제품과 일치하는가?
□ 영양소 함량이 검사 성적서와 일치하는가?
□ 제조 과정(정제, 살균)이 정직하게 표현되었는가?
□ 할인율이 합리적인가?
□ 비교 표현이 객관적 사실만 포함하는가?
□ 고혈압/신장질환자 주의사항이 안내되어 있는가?
□ 70년 기술력이 구체적으로 설명되어 있는가?
□ 환경 인증/보존 활동이 있는가?
□ 고객 리뷰가 실제 판매처와 일치하는가?
□ 사용 방법(하루 권장량)이 명확한가?
```

### 2️⃣ 뷰티 (💄 미네랄 에센스, 피부 제품)

**총 13개 검증 항목**

#### Critical (불통과 조건)
- ❌ 의약품 용어 사용 (치료, 재생, 재생력, 피부질환 등)
- ❌ 천연/유기농 인증 부재
- ❌ 성분 안전성 미검증 (중금속 등)

#### High Priority (경고 조건)
- ⚠️ 부작용 공시 부재
- ⚠️ 사용법의 불명확성
- ⚠️ 필터/보정 공시 누락
- ⚠️ 임상 근거 부족
- ⚠️ 셀럽 광고에 "광고" 표시 부재
- ⚠️ 제조지 미명시

#### 마케터 수동 체크

```
□ 천연/유기농 인증서가 있는가? (ECOCERT, USDA Organic 등)
□ 모든 성분이 공개되어 있는가?
□ 알려진 부작용이 안내되어 있는가?
□ 사용법이 단계별로 명확한가?
□ 필터/보정이 공시되어 있는가?
□ 임상 근거(논문, 제3기관 시험)가 있는가?
□ 셀럽 광고에 "광고" 표시되어 있는가?
□ 제조처/원산지가 명시되어 있는가?
□ 동물실험 미수행 인증이 있는가?
□ 피부 타입별 안전성이 안내되어 있는가?
□ 지속가능 패키징에 대한 근거가 있는가?
□ 가격이 경쟁사와 비교해 과도하지 않은가?
□ 이미지(비포/애프터)가 같은 조건에서 촬영되었는가?
```

### 3️⃣ 헬스/영양제 (💊 미네랄 영양보조제, 기능식품)

**총 15개 검증 항목**

#### Critical (불통과 조건)
- ❌ 의학적 효능/치료 주장 (질병 예방, 혈압 조절 등)
- ❌ 건강기능식품 인증 부재
- ❌ 성분/함량 부정확성
- ❌ 부작용/금기사항 미공시

#### High Priority (경고 조건)
- ⚠️ 개인차 고지 부재
- ⚠️ 의료 전문가 상담 권유 부재
- ⚠️ 섭취 방법 불명확
- ⚠️ 과학적 근거(임상, 논문) 부족
- ⚠️ 셀럽 광고에 "광고" 표시 부재
- ⚠️ GMP 인증 부재

#### 마케터 수동 체크

```
□ 식약처 건강기능식품 허가 번호가 있는가?
□ 인정된 기능성이 마케팅과 일치하는가?
□ 1회 섭취량, 일일 권장량이 명시되어 있는가?
□ 신장질환자, 임산부 등 금기사항이 명시되어 있는가?
□ 의약품과의 상호작용 정보가 있는가?
□ "의료 전문가와 상담하세요" 안내가 있는가?
□ "개인차가 있을 수 있습니다" 고지가 있는가?
□ 임상 시험 결과의 출처가 명확한가?
□ 논문 인용 시 SCI 등재인가?
□ 통계 수치의 샘플 크기가 명시되어 있는가?
□ 부정적 결과나 한계도 언급되었는가?
□ 셀럽 광고에 "광고" 표시되어 있는가?
□ GMP 인증서가 있는가?
□ 제조처가 명시되어 있는가?
□ 보관법/유효기간이 명시되어 있는가?
```

         ↓

         ↓

         ↓
Step 9-2: Phase 1 - 자동 검증 실행

         ├─ Critical 이슈 감지
         └─ 경고 표현 감지
         ↓
         ├─ Critical 이슈 감지? → REJECTED (재작성 필요)
         │                         ↓
         │                    Step 6: 카피 재작성
         │
         └─ Critical 없음? → 계속 진행
                             ↓
Step 9-3: Phase 2 - 수동 체크리스트 생성
         ├─ 마케터에게 체크리스트 제시 (10~15개 항목)
         ├─ "원산지 검증", "인증 확인" 등 상세 항목
         └─ 마케터가 각 항목 검토 (3~5분)
         ↓
         ↓ 마케터 검증 완료
         ↓

         ├─ 자동 경고 있음 + 마케터 검증 완료 → WARNING (수정 권고)
         ├─ 자동 경고 없음 + 마케터 OK → PASS
         └─ Critical 이슈 → REJECTED
         ↓
         ✅ 완료 또는 → 재작업

## 📊 판정 결과 해석

### PASS_AUTO (자동 검증 완료)
- 자동 검증에서 경고/critical 없음
- 수동 검증 대기 중
- 마케터가 체크리스트로 최종 확인 필요

### WARNING (경고)
- 자동 검증에서 경고 이슈 감지 또는
- 수동 검증에서 일부 항목 불통과
- **권고**: 카피 수정 후 Step 8 재생성

### PASS (통과)
- 자동 검증 완료 + 수동 검증 완료
- 모든 항목 합격
- ✅ 최종 출시 가능

### REJECTED (불통과)
- Critical 이슈 감지 (의약품 표현, 거짓 원산지 등)
- **필수**: Step 6(카피 재작성) 또는 Step 3(캐릭터 변경)부터 재시작

## 🛠️ 마케터 실무 체크리스트

각 카테고리별 가장 중요한 5가지:

### 식품
1. 원산지 명시 + 인증서 확인
2. 영양소 함량 (검사 성적서 일치 확인)
3. 의약품 표현 제거 (「치료」「예방」 없음)
4. 할인율 합리성 (60% 이하)
5. 타겟 주의사항 (고혈압자, 임산부 등)

### 뷰티
1. 천연/유기농 인증 확인
2. 성분 공개 + 안전성 검증
3. 의약품 용어 제거 (「재생」「치유」 없음)
4. 비포/애프터 이미지 진정성
5. 필터/보정 공시

### 헬스
1. 식약처 건강기능식품 허가 확인
2. 부작용/금기사항 명시
3. 의학적 표현 제거 (「예방」「조절」 없음)
4. 임상 근거 검증 (논문/기관 명시)
5. 의료 상담 권유 안내

## 📞 예외/특수 상황

**Q: 임상 시험을 진행 중인데 결과를 먼저 공지할 수 있을까?**
→ 불가. 완료된 임상만 홍보 가능. 진행 중이면 "임상 진행 중" 안내만 가능.

**Q: "자연"이라는 표현은 괜찮을까?**
→ 제조 과정(정제, 살균)이 있다면 "자연 그대로"는 피하고, "자연에서 채취한"으로 변경.

**Q: 비포/애프터 사진에 메이크업을 했다면 공시해야 할까?**
→ YES. "메이크업 포함" 또는 "영상 보정" 명시 필수.

**Q: 다른 제품과 비교해도 될까?**
→ 객관적 수치(함량, 성분)로만 비교. 정성적 표현(\"효과\", \"품질\") 비교는 금지.
