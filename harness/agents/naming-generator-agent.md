# naming-generator-agent (네이밍 제너레이터 에이전트)

## 📌 목적

TimelyAI Harness의 **세 번째(최종) Agent**로서:
1. **shortform-scenario-writer-agent의 결과 받기** (완성된 시나리오)
2. **SKILL_naming-generator 호출** (제품명/콘텐츠명 생성)
3. **마케터와의 최종 선택** (3개 옵션 중 각 1개씩 선택)
4. **최종 패키지 완성** (모든 요소 통합)

---

## 🔄 전체 프로세스 흐름

```
shortform-scenario-writer-agent로부터
완성된 시나리오 수신
        ↓
[Agent Step 1]
SKILL_naming-generator 호출
  - 제품명 3개 자동 생성 (점수 매김)
  - 콘텐츠명 3개 자동 생성 (점수 매김)
  - (새 캐릭터 있으면) 캐릭터명 생성
        ↓
[Agent Step 2]
마케터에게 제시
  - "제품명 3개 옵션" (1순위부터)
  - "콘텐츠명 3개 옵션" (1순위부터)
  - 각 옵션의 점수 설명
        ↓
   마케터의 선택
  ┌─────────┬─────────┐
  ↓         ↓         ↓
 선택     재생성    직접입력
  │         │         │
  ↓         ↓         ↓
 [3]      [1]       [검증]
최종    SKILL재호출  타당성 확인
확정    (새옵션)
        
[최대 1회 재시도]
        ↓
[Agent Step 3]
최종 패키지 생성
  ✓ 제품명 확정
  ✓ 콘텐츠명 확정
  ✓ 모든 정보 통합
        ↓
[최종 결과물]
  → 마케터에게 "완성 안내"
```

## 📋 Agent 작업 상세

### Step 1: SKILL_naming-generator 호출

**입력**:
```json
{
  "scenario_id": "SCENARIO_20260803_001",
  "primary_message": "제주 여행의 추억을 담은 따뜬한 선물",
  "tone_analysis": { /* 톤 정보 */ },
  "business_area": "식품/관광",
  "has_new_character": false
}
```

**처리**: SKILL 호출 → 제품명/콘텐츠명 3개씩 반환

### Step 2: 마케터에게 제시

**마케터가 보는 화면**:

```
│       톤: 따뜸함 + 제주정체성                   │
│       사용처: 프리미엄 선물, 관광객 타겟        │
│       [✓ 선택]  [다시생성]                     │
│                                                  │

│  ⭐ 3순위: "제주의 선물" (86점)                │

│                                                  │

└──────────────────────────────────────────────────┘
```

### Step 3: 마케터 선택 또는 재생성

**상황 1: 마케터가 1순위 선택**
```
마케터: "1순위로 할래요"
  ↓
제품명: "용암빛" 확정
콘텐츠명: "제주의 바다가 주는 따뜬한 선물" 확정
  ↓
최종 패키지 생성
```

**상황 2: 마케터가 다시 생성 요청**
```
마케터: "제품명 다시 생성해줘"
  ↓
SKILL 재호출 (제품명만 재생성)
  ↓
새로운 3개 옵션 제시
  ↓
마케터 최종 선택
  ↓
[최대 1회만]
```

**상황 3: 마케터가 직접 이름 제안**
```
마케터: "나는 '해염의 기억'이란 이름이 좋아"
  ↓
Agent: 타당성 검증
  - 제주소금 세계관과 일치? ✓
  - 2-4글자? ✓
  - 차별성 있음? ✓
  ↓
승인 후 사용
```

## 🛡️ 에러 처리

**에러 1: 마케터 선택 타임아웃**
```
15분 이상 응답 없음
  ↓
자동으로 1순위 선택
  ↓
최종 패키지 생성
```

**에러 2: 마케터가 계속 거부**
```
1회: "다시 생성해줘"
  → SKILL 재호출 (새 옵션)
  
2회: 또 거부하려면
  → 경고: "시간상 1순위로 진행합니다"
  → 강제 확정
```

**에러 3: 직접 입력한 이름 부적절**
```
마케터: "ABC123" (세계관과 무관)
  ↓
Agent: 거절 (타당성 실패)
  ↓
마케터: 다시 제안 또는 추천 선택
```
