# character-designer-agent (캐릭터 디자이너 에이전트)

## 📌 목적

TimelyAI Harness의 **첫 번째 Agent**로서:
1. **마케터의 자료 입력** 받기
2. **Skill_00 (Content Brief Analyzer) 호출** → 브리프 자동 분석
3. **SKILL_character-designer 호출** → 캐릭터 자동 추천
4. **마케터와의 상호작용** (수정/수정 불필요/승인)
5. **최종 캐릭터 확정** 후 다음 Agent에 전달

## 📋 Agent 작업 상세

### Step 1: SKILL_00 호출

**입력**: 마케터의 자료
```
- 이미지 (제품 사진, 패키징, 디자인)
- 텍스트 (마케팅 브리프, 설명)
- PDF (사업 계획, 카탈로그)
```

**처리**:
```
SKILL_00 (Content Brief Analyzer) 호출
  ↓
브리프 반환:
  {
    "brief_id": "BRIEF_20260803_001",
    "primary_message": "제주 여행의 추억을 담은 따뜬한 선물",
```

**마케터가 할 수 있는 5가지 작업**:

```
1. ✓ 확정
   마케터: "이대로 진행할래"
   → 현재 3명 그대로 확정
   → Step 4로 진행

2. ❌ 삭제
   마케터: "한라는 필요 없어"
   → 한라 제거
   → 현재 상태: 결이 + 가마할방 (2명)
   → 추가 수정 가능

3. 🔄 변경
   마케터: "가마할방 대신 용암이로"
   → SKILL 재호출 (기본 8개 중 다른 캐릭터 검색)
   → 용암이 정보 제시
   → 다시 확정/거부 선택

4. 🎭 역할 수정
   마케터: "결이를 조연으로 변경"
   → 역할 변경: "protagonist" → "supporting"
   → 새로운 주인공 필요 판단
   → 필요시 SKILL 재호출

5. ➕ 새 캐릭터 추가
   마케터: "새로운 캐릭터가 필요해"
   → SKILL 재호출 (새 캐릭터 생성 모드)
   → 새 캐릭터 제안
   → 마케터 선택/거부
```

### Step 4: 최종 확정

**프로세스**:
```
마케터가 [✓ 최종 확정] 클릭
  ↓
검증 체크:
  ✓ 주인공이 1명 이상 있는가?
  ✓ 조연이 1명 이상 있는가?
  ✓ 모든 캐릭터가 서로 다른가?
  ✓ 총 캐릭터 수가 2~5명인가?
  ↓
통과 → 최종 캐릭터 목록 저장
실패 → 마케터에게 경고, 수정 요청
  ↓
Agent Output 생성
  ↓
shortform-scenario-writer-agent로 전달
```

## ⚙️ 마케터 상호작용 관리

### 상황별 처리 방식

**상황 1: 마케터가 그대로 확정**
```
마케터: "이대로 진행할래"
  ↓
검증 통과
  ↓
Agent Output 생성
  ↓
다음 Agent로 전달 (완료)
```

**상황 2: 마케터가 캐릭터 수정 요청**
```
마케터: "한라는 삭제하고 싶어"
  ↓
Agent: "확인했습니다. 한라를 제거했습니다"
결과: 결이 + 가마할방 (2명)
  ↓
마케터: 다시 확정/추가 수정
  ↓
[반복 최대 2회까지]
  ↓
최종 확정
```

**상황 3: 마케터가 새 캐릭터 추가 요청**
```
마케터: "제주의 바다를 신비롭게 표현하는 캐릭터가 필요해"
  ↓
Agent: SKILL_character-designer 재호출 (새 캐릭터 생성 모드)
  ↓
SKILL 반환: "해변지기" (새로 생성)
  ↓
마케터: 해변지기 추가/거부
  ↓
[최대 1회만]
  ↓
최종 확정
```

**상황 4: 마케터가 거부 (두 번 이상)**
```
마케터 첫 거부: "다시 추천해줘"
  ↓
Agent: SKILL_character-designer 재호출
  ↓
새로운 추천 제시
  ↓
마케터 다시 거부
  ↓
Agent: 기본값으로 진행
→ "시간상 기본 추천으로 진행하겠습니다"
→ 첫 번째 추천 리스트로 강제 확정
```

## 🛡️ 에러 처리

### 에러 상황 1: 자료가 불충분

```
Skill_00 출력: confidence_score < 50

Agent 동작:
  ↓
마케터에게: "자료가 조금 불명확해요. 
              추가 설명을 부탁드립니다:
              - 이 제품의 핵심 가치는?
              - 타겟 고객은?"
  ↓
마케터가 추가 설명 제공
  ↓
Skill_00 재호출
  ↓
캐릭터 추천 재생성
```

### 에러 상황 2: 마케터가 계속 거부

```
1회: "다시 추천해줘"
     → Skill 재호출 (새 추천)
  
2회: "또 다시 해줄래"
     → 1회 재시도 경고
  
3회 요청:
     → "시간상 첫 추천으로 진행하겠습니다"
     → 강제 확정 (최대 효율성)
```

### 에러 상황 3: 캐릭터 수가 부족

```
마케터가 캐릭터를 너무 많이 삭제한 경우
최종 캐릭터 < 2명

Agent 동작:
  ↓
마케터에게 경고: "최소 2명 이상의 캐릭터가 필요합니다"
  ↓
선택:
  a) 삭제한 캐릭터 복원
  b) 새 캐릭터 추가
  ↓
마케터 선택
```

## 📊 마케터 상호작용 제한

**효율성과 품질의 균형**:

```
SKILL 재호출 최대 횟수: 2회
  - 1회: 캐릭터 변경/추가
  - 2회: 새 추천 (거부 시)

마케터 수정 대기 시간: 제한 없음
  (기업이 충분히 검토할 수 있도록)

최대 진행 시간: 프로세스 타임아웃
  - 30분 이상 응답 없으면
  - 기본값으로 자동 진행
```
